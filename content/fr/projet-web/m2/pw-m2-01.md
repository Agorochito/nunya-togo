## Explication pas à pas

Ta page a maintenant tout son contenu. Le deuxième module lui donne une apparence. Dans un vrai site, le style vit souvent dans un fichier séparé relié par une balise link ; pour ce projet d’une seule page, on écrit le CSS dans une balise style placée dans head. Les règles sont les mêmes, et tout le projet tient dans un seul fichier facile à publier.

Commence par quelques règles générales. body { margin: 0 } retire la marge par défaut du navigateur. Une police système, font-family: system-ui, sans-serif, s’affiche vite, sans téléchargement, ce qui compte avec une connexion limitée. Ensuite, le contenu ne doit pas s’étaler sur toute la largeur d’un grand écran : des lignes de 200 caractères sont pénibles à lire. On limite donc la largeur de main avec max-width: 720px et on le centre avec margin: 0 auto. Sur un téléphone plus étroit que 720 pixels, main prend simplement toute la largeur disponible : max-width fixe un maximum, pas une largeur obligatoire. Un padding de 16 pixels évite que le texte touche les bords de l’écran.

Les couleurs méritent une attention particulière. Une page utilise en général trois ou quatre couleurs : un fond, un texte, un accent pour les titres et les liens, parfois une couleur secondaire. Si tu écris #1f5e46 dans dix règles, changer d’accent demande dix modifications, avec le risque d’en oublier une. Les propriétés personnalisées, appelées aussi variables CSS, règlent ce problème. On les déclare dans :root, qui désigne l’élément html : --accent: #1f5e46. Leur nom commence obligatoirement par deux tirets. On les utilise ensuite avec var(--accent).

Changer l’identité de la page devient alors une modification de trois lignes, en haut de la feuille de style. C’est le principe de nombreux thèmes, y compris les ambiances de Nunya. Les variables suivent la cascade : une variable déclarée sur :root est disponible partout.

Attention aux fautes de frappe : var(--accnet) ne provoque aucune erreur visible. La propriété est simplement ignorée et l’élément garde sa couleur précédente. Si une couleur ne s’applique pas, vérifie d’abord l’orthographe de la variable, puis l’outil d’inspection du navigateur, qui affiche les règles appliquées.

Dans les exercices, l’aperçu calcule le style réel de chaque élément, après la cascade : il vérifie ce que le navigateur affiche vraiment, pas seulement ce que tu as écrit.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ama Mensah — page personnelle</title>
  <style>
    :root {
      --fond: #fdfaf5;
      --texte: #1d1d1f;
      --accent: #1f5e46;
    }
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: var(--fond);
      color: var(--texte);
    }
    main {
      max-width: 720px;
      margin: 0 auto;
      padding: 16px;
    }
    h1, h2 {
      color: var(--accent);
    }
  </style>
</head>
<body>
  <main>
    <h1>Ama Mensah</h1>
    <h2>À propos</h2>
    <p>Élève à Lomé.</p>
  </main>
</body>
</html>

```

Résultat attendu : Un contenu centré sur 720 pixels au plus, sur fond crème, avec des titres verts.

Trace :

- Les trois couleurs sont déclarées une seule fois dans :root.
- body et les titres les utilisent avec var().
- main est limité à 720 pixels et centré.

      background-color: var(--fond);
      color: var(--texte);
    }
    main {
      max-width: 720px;

      padding: 16px;
    }
    h1, h2 {
      color: var(--accent);
    }

<body>
  <main>
    <h1>Ama Mensah</h1>
