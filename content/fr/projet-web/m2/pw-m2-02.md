## Explication pas à pas

Le style ne sert pas qu’à décorer : il décide si la page est lisible. Les deux premiers critères sont le contraste et la taille du texte.

Le contraste mesure la différence de luminosité entre le texte et son fond. Les règles d’accessibilité du web, les WCAG, demandent un rapport d’au moins 4,5 pour 1 pour le texte courant, et 3 pour 1 pour les grands titres. Un gris clair comme #b8b8b8 sur fond blanc n’atteint qu’environ 2 pour 1 : il paraît élégant sur un écran neuf dans une pièce sombre, mais devient illisible au soleil, sur un téléphone d’entrée de gamme ou pour une personne qui voit mal. Un gris foncé comme #333333 dépasse 12 pour 1. Des outils en ligne, et les outils de développement des navigateurs, calculent ce rapport pour toi ; vérifie chaque couple texte-fond de ta page.

Le contraste concerne aussi les liens. Un lien doit se distinguer du texte qui l’entoure. La couleur seule ne suffit pas pour les personnes qui ne distinguent pas certaines couleurs : garde le soulignement, text-decoration: underline, qui est le signal universel d’un lien dans un paragraphe.

La taille du texte vient ensuite. Les navigateurs utilisent 16 pixels par défaut ; pour une page de lecture, 17 ou 18 pixels sont plus confortables, surtout sur un téléphone. Évite les tailles inférieures à 14 pixels pour du texte important. Les titres suivent une échelle : par exemple 32 pixels pour le h1, 24 pour les h2, 20 pour les h3. Une échelle régulière donne une impression d’ordre ; des tailles choisies au hasard donnent une impression de désordre.

La hauteur de ligne, line-height, aère le texte : une valeur entre 1,5 et 1,7 convient aux paragraphes. Enfin, limite les polices : une seule famille, voire deux, suffit. Chaque police téléchargée ralentit la page, et plusieurs styles différents fatiguent l’œil.

Une palette réussie reste simple : un fond clair ou sombre, un texte très contrasté, un accent pour les titres et les liens, utilisé avec mesure. Si tout est coloré, plus rien ne ressort. Teste ta page en plein jour sur un téléphone : c’est souvent là que les problèmes de contraste apparaissent.

Dans les exercices, l’aperçu vérifie les couleurs et tailles calculées. Le calcul du contraste lui-même se fait avec les outils cités, que tu utiliseras sur ta vraie page.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ama Mensah — page personnelle</title>
  <style>
    :root {
      --texte: #1d1d1f;
      --accent: #1f5e46;
    }
    body {
      font-size: 18px;
      color: var(--texte);
      background-color: #ffffff;
    }
    h1 {
      font-size: 32px;
      color: var(--accent);
    }
    h2 {
      font-size: 24px;
      color: var(--accent);
    }
    a {
      color: var(--accent);
      text-decoration: underline;
    }
  </style>
</head>
<body>
  <main>
    <h1>Ama Mensah</h1>
    <h2>Projets</h2>
    <p>Mon quiz : <a href="#quiz">voir le quiz</a>.</p>
  </main>
</body>
</html>

```

Résultat attendu : Un texte de 18 pixels, des titres de 32 et 24 pixels, et des liens soulignés de la couleur d’accent.

Trace :

- Le texte courant passe à 18 pixels.
- Les titres suivent une échelle régulière.
- Les liens restent soulignés.

## Exemple guidé 2

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ama Mensah — page personnelle</title>
  <style>
    body {
      background-color: #ffffff;
    }
    .faible {
      color: #b8b8b8;
    }
    .lisible {
      color: #333333;
    }
  </style>
</head>
<body>
  <main>
    <p class="faible">Texte trop pâle : environ 2 pour 1.</p>
    <p class="lisible">Texte lisible : plus de 12 pour 1.</p>
  </main>
</body>
</html>

```

Résultat attendu : Deux paragraphes sur fond blanc : le premier échoue au contraste, le second le respecte largement.

Trace :

- #b8b8b8 sur blanc : environ 2 pour 1.
- #333333 sur blanc : plus de 12 pour 1.
- Le minimum pour du texte courant est 4,5 pour 1.

## Vérifier et expliquer

Vérifie avec un outil de contraste les couleurs de texte et de fond que tu as choisies pour ta page.
