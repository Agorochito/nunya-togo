## Explication pas à pas

Un lien mailto suffit souvent pour te contacter. Un formulaire offre une autre possibilité : le visiteur écrit son message directement sur ta page. Pour une page personnelle, trois champs suffisent : le nom, l’adresse électronique et le message. Chaque champ de plus fait fuir des visiteurs.

Chaque champ a besoin d’une étiquette. La balise label, reliée au champ par for et id identiques, affiche le texte et le rend utile : un lecteur d’écran annonce « Ton nom, zone de texte », et un clic sur l’étiquette place le curseur dans le champ, ce qui aide sur les petits écrans. Un texte d’exemple dans placeholder ne remplace pas une étiquette : il disparaît dès qu’on commence à écrire.

Le type du champ aide le visiteur. type="email" affiche un clavier adapté sur téléphone, avec le caractère @, et vérifie le format de l’adresse. L’attribut autocomplete, avec les valeurs name et email, permet au navigateur de proposer les informations déjà connues : un gain de temps précieux sur un téléphone. Le message utilise textarea, une zone de plusieurs lignes, avec rows pour sa hauteur.

L’attribut required rend un champ obligatoire. Si le visiteur l’oublie, le navigateur bloque l’envoi et affiche un message, sans aucun script. Cette validation améliore l’expérience, mais elle ne protège rien : n’importe qui peut la contourner. Le serveur qui reçoit les messages doit toujours vérifier les données lui-même, comme expliqué dans le cours de cybersécurité.

Car un formulaire a besoin d’un serveur pour envoyer quoi que ce soit. L’attribut action indique l’adresse qui recevra les données, method="post" la façon de les envoyer. Une page statique, comme celle que tu publieras, n’a pas de serveur. Deux solutions existent : garder simplement le lien mailto, ou utiliser un service de formulaires qui reçoit les messages et te les transmet par courriel. Dans ce cas, lis ses conditions : il conservera les messages de tes visiteurs. Le cours PHP de Nunya montre comment écrire toi-même la partie serveur.

Le bouton d’envoi doit dire ce qu’il fait : « Envoyer le message » plutôt que « OK ». Un button de type submit envoie le formulaire. Dans l’aperçu de Nunya, l’envoi est bloqué : aucun message ne part, mais la structure et les attributs sont vérifiés.

Enfin, ne demande jamais plus que nécessaire : pas de numéro de téléphone, pas d’adresse postale. Moins tu collectes de données, moins tu as à protéger.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
</head>
<body>
  <main>
    <section id="contact">
      <h2>Contact</h2>
      <form action="https://formulaire.example.com/ama" method="post">
        <label for="nom">Ton nom</label>
        <input id="nom" name="nom" type="text" autocomplete="name" required>
        <label for="courriel">Ton adresse électronique</label>
        <input id="courriel" name="courriel" type="email" autocomplete="email" required>
        <label for="message">Ton message</label>
        <textarea id="message" name="message" rows="5" required></textarea>
        <button type="submit">Envoyer le message</button>
      </form>
    </section>
  </main>
</body>
</html>

```

Résultat attendu : Trois champs étiquetés, obligatoires, avec les bons types et l’auto-remplissage.

Trace :

- Chaque label est relié à son champ par for et id.
- Le champ de courriel a le type email.
- Le bouton annonce clairement l’action.

## Exemple guidé 2

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
</head>
<body>
  <main>
    <form>
      <label for="ville">Ta ville</label>
      <input id="ville" name="ville" type="text" placeholder="Ex. : Kara">
    </form>
  </main>
</body>
</html>

```

Résultat attendu : Une étiquette visible et un exemple dans le champ : les deux se complètent.

Trace :

- L’étiquette reste visible pendant la saisie.
- placeholder donne seulement un exemple.
- Le champ n’est pas obligatoire.

## Vérifier et expliquer

Remplis un formulaire en ligne sur ton téléphone et note ce qui t’aide ou te gêne : clavier, étiquettes, messages d’erreur.
