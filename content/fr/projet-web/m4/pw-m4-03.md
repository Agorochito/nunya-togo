## Explication pas à pas

Ce dernier chapitre réunit tout le projet dans un seul fichier : le squelette du premier module, la feuille de style du deuxième, les règles adaptatives du troisième et les interactions de celui-ci. Prends le temps de l’assembler dans l’ordre : structure HTML complète d’abord, puis style de base, puis requête média, puis détails d’interaction. Relance l’aperçu à chaque étape.

Avant de publier, passe la page au crible d’une liste de contrôle. Structure : la langue est déclarée, le titre d’onglet est précis, il y a un seul h1, les titres se suivent sans sauter de niveau, les régions header, nav, main et footer sont présentes. Contenus : chaque image a un texte alternatif, chaque lien annonce sa destination, aucune donnée personnelle sensible n’apparaît. Style : le contraste dépasse 4,5 pour 1, le texte fait au moins 16 pixels, les liens restent soulignés. Téléphone : la balise viewport est là, rien ne déborde à 360 pixels, aucune information essentielle n’est masquée. Clavier : chaque lien reçoit un focus visible quand on appuie sur Tab.

Fais ensuite tester la page par quelqu’un d’autre, de préférence sur son propre téléphone. Ne lui explique rien : observe où cette personne hésite. Ces observations valent plus que toutes les relectures.

Pour publier gratuitement une page statique, GitHub Pages est une solution répandue. Le cours Git et GitHub de Nunya t’apprend à créer un dépôt et à y envoyer tes fichiers. Le fichier principal s’appelle index.html. Dans les réglages du dépôt, la section Pages permet de choisir la branche à publier ; quelques minutes plus tard, la page est accessible à une adresse en github.io. D’autres services gratuits existent sur le même principe. Il faut un compte, et donc une adresse électronique ; demande l’accord d’un adulte si tu as moins de l’âge requis par le service.

Une fois publiée, ta page vit. Ajoute chaque nouveau projet terminé, mets à jour ta présentation chaque année, retire ce qui ne te représente plus. Garde l’historique de tes modifications avec Git : tu pourras toujours revenir en arrière.

Enfin, cette page est un point de départ. Avec les cours JavaScript, tu pourras ajouter des interactions plus riches ; avec React, construire des interfaces plus complexes ; avec PHP ou Node.js, recevoir réellement les messages du formulaire. Mais une page simple, rapide, lisible et accessible fait déjà une très bonne impression.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
  <style>
    :root {
      --fond: #fdfaf5;
      --texte: #1d1d1f;
      --accent: #1f5e46;
    }
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      font-size: 18px;
      background-color: var(--fond);
      color: var(--texte);
    }
    header,
    main,
    footer {
      max-width: 720px;
      margin: 0 auto;
      padding: 16px;
    }
    nav {
      display: flex;
      flex-direction: column;
      gap: 8px;
    }
    h1,
    h2 {
      color: var(--accent);
    }
    img {
      max-width: 100%;
      height: auto;
    }
    .projets {
      display: grid;
      gap: 16px;
    }
    a:focus-visible {
      outline: 3px solid var(--accent);
    }
    @media (min-width: 700px) {
      nav {
        flex-direction: row;
      }
      .projets {
        grid-template-columns: 1fr 1fr;
      }
    }
  </style>
</head>
<body>
  <header>
    <h1>Ama Mensah</h1>
    <p>Élève en première, passionnée de code et de dessin.</p>
  <nav aria-label="Sections de la page">
    <a href="#apropos">À propos</a>
    <a href="#projets">Projets</a>
    <a href="#contact">Contact</a>
  </nav>
  </header>
  <main>
    <section id="apropos">
      <h2>À propos</h2>
      <img src="portrait-ama.jpg" alt="Portrait d’Ama Mensah souriante" width="160" height="160">
      <p>J’apprends à programmer depuis un an.</p>
    </section>
    <section id="projets">
      <h2>Projets</h2>
      <div class="projets">
        <article><h3>Quiz de révision</h3><p>Un quiz en Python.</p></article>
        <article><h3>Site du club</h3><p>Une page HTML et CSS.</p></article>
      </div>
    </section>
    <section id="contact">
      <h2>Contact</h2>
      <details>
        <summary>Comment me joindre ?</summary>
        <p><a href="mailto:ama.mensah@example.com">Écrire à Ama</a></p>
      </details>
    </section>
  </main>
  <footer>
    <p>Page fictive réalisée dans Nunya, 2026.</p>
  </footer>
</body>
</html>

```

Résultat attendu : La page complète d’Ama, vue sur téléphone.

Trace :

- Structure : langue, titre, viewport, régions et sections.
- Style : variables, colonne lisible, images souples.
- Interaction : un volet pour le contact.
