## Explication pas à pas

Une page vivante répond aux gestes du visiteur. Beaucoup de développeurs ajoutent du JavaScript pour la moindre interaction, alors que HTML et CSS en proposent déjà plusieurs, accessibles au clavier et aux lecteurs d’écran sans aucun effort, et qui fonctionnent même si les scripts sont bloqués.

L’élément details crée un volet dépliable. Son premier enfant, summary, est le titre toujours visible ; le reste du contenu apparaît quand on clique sur ce titre ou qu’on appuie sur Entrée. L’attribut open le déplie dès le chargement. C’est parfait pour une foire aux questions : la page reste courte, et chacun déplie ce qui l’intéresse. Le navigateur gère seul l’état ouvert ou fermé et l’annonce aux technologies d’assistance.

Les ancres de la navigation font déjà défiler la page vers les sections. La règle html { scroll-behavior: smooth } rend ce défilement progressif au lieu d’un saut brusque. Certaines personnes ressentent toutefois un malaise avec les mouvements à l’écran et l’ont signalé dans les réglages de leur appareil. On respecte ce choix avec une requête média : @media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto } }. Nunya applique la même règle à ses propres animations.

L’indicateur de focus est essentiel pour qui navigue au clavier : il montre quel lien est actif quand on appuie sur Tab. Les navigateurs en affichent un par défaut, souvent discret. Ne le supprime jamais avec outline: none sans le remplacer. Le sélecteur :focus-visible permet de dessiner un indicateur clair, par exemple outline: 3px solid suivi de ta couleur d’accent, qui apparaît pour le clavier sans gêner les clics à la souris. outline-offset l’éloigne légèrement du texte pour plus de lisibilité.

Les états :hover, au survol de la souris, ajoutent une réaction visuelle : une carte qui se soulève légèrement, un lien qui change de couleur. Ils restent un bonus, car les écrans tactiles n’ont pas de survol : aucune information ne doit dépendre uniquement de :hover.

Enfin, une transition douce, transition: transform 0.2s, rend ces changements agréables. Comme pour le défilement, désactive-la quand l’utilisateur préfère réduire les animations.

Dans les exercices, l’aperçu peut placer le focus sur un élément, comme le ferait la touche Tab, puis vérifier le style calculé.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
</head>
<body>
  <main>
    <section id="questions">
      <h2>Questions fréquentes</h2>
      <details>
        <summary>Quels langages utilises-tu ?</summary>
        <p>HTML, CSS et Python.</p>
      </details>
      <details>
        <summary>Fais-tu des sites pour des associations ?</summary>
        <p>Oui, bénévolement, pour apprendre.</p>
      </details>
    </section>
  </main>
</body>
</html>

```

Résultat attendu : Deux questions dépliables ; aucune ligne de script.

Trace :

- details contient summary puis la réponse.
- Le navigateur gère l’ouverture au clic et au clavier.
- La page reste courte.

## Exemple guidé 2

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
  <style>
    html {
      scroll-behavior: smooth;
    }
    @media (prefers-reduced-motion: reduce) {
      html {
        scroll-behavior: auto;
      }
    }
    a:focus-visible {
      outline: 3px solid #1f5e46;
      outline-offset: 2px;
    }
  </style>
</head>
<body>
  <nav aria-label="Sections de la page">
    <a href="#projets">Projets</a>
  </nav>
  <section id="projets"><h2>Projets</h2></section>
</body>
</html>

```

Résultat attendu : Un défilement doux qui respecte la préférence de mouvement réduit, et un focus clavier bien visible.

Trace :

- scroll-behavior: smooth adoucit le défilement des ancres.
- La requête prefers-reduced-motion le désactive si l’utilisateur le demande.
- Le lien focalisé reçoit un contour de 3 pixels.

## Vérifier et expliquer

Parcours ta page uniquement avec la touche Tab et note chaque endroit où tu perds le focus de vue.
