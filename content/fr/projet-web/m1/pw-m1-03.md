## Explication pas à pas

Un visiteur qui arrive sur une page personnelle cherche surtout des preuves : qu’as-tu réalisé ? La section Projets répond à cette question. Chaque projet est un contenu autonome, qui aurait du sens seul : la balise article lui convient parfaitement. Il contient un titre h3, puisque la section a déjà son h2, une ou deux phrases qui expliquent le projet et ce que tu as appris, puis un lien pour en voir plus.

Trois ou quatre projets bien présentés valent mieux que dix projets vagues. Pour chacun, précise l’outil utilisé et le résultat : « Un quiz en Python pour réviser le bac, avec score final » est plus parlant que « Projet Python ». Les exercices des cours de Nunya peuvent devenir tes premiers projets.

Le texte d’un lien doit annoncer sa destination. « Cliquez ici » ou « Lien » ne disent rien hors contexte, or beaucoup de personnes parcourent les liens d’une page comme une liste, au clavier ou avec un lecteur d’écran. « Voir le code du quiz » ou « Écrire à Ama » sont compris sans lire le reste.

Il existe trois sortes de liens. Un lien interne vise une partie de la page : href="#contact". Un lien externe vise une autre adresse, qui commence par https://. Si tu choisis de l’ouvrir dans un nouvel onglet avec target="_blank", ajoute rel="noopener" : cet attribut empêche la page ouverte d’agir sur la tienne, une précaution de sécurité. Ne l’utilise pas partout : par défaut, laisser le visiteur décider est plus respectueux. Un lien mailto: ouvre l’application de messagerie avec l’adresse déjà remplie : href="mailto:ama.mensah@example.com".

Pour te contacter, une adresse électronique dédiée suffit. Évite de publier ton numéro de téléphone personnel : une page publique peut être lue par n’importe qui, y compris des personnes mal intentionnées et des robots qui collectent les adresses. Certains créent une adresse réservée à leurs candidatures. Le domaine example.com, utilisé dans ce cours, est réservé aux exemples et ne correspond à personne.

Enfin, vérifie chaque lien : un lien cassé donne une mauvaise impression. Dans l’aperçu de Nunya, les liens sont désactivés pour ta sécurité, mais leurs attributs sont contrôlés ; sur ta vraie page, clique chacun d’eux avant de publier.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ama Mensah — page personnelle</title>
</head>
<body>
  <main>
    <section id="projets">
      <h2>Projets</h2>
      <article>
        <h3>Quiz de révision</h3>
        <p>Un quiz en Python pour réviser le bac.</p>
        <a href="https://github.com/exemple/quiz" target="_blank" rel="noopener">Voir le code du quiz</a>
      </article>
      <article>
        <h3>Site du club de lecture</h3>
        <p>Une page HTML et CSS pour annoncer les rencontres.</p>
        <a href="#contact">Me demander une démonstration</a>
      </article>
    </section>
    <section id="contact">
      <h2>Contact</h2>
      <p><a href="mailto:ama.mensah@example.com">Écrire à Ama</a></p>
    </section>
  </main>
</body>
</html>

```

Résultat attendu : Deux projets dans des articles, des liens explicites et un lien de contact par courriel.

Trace :

- Chaque article a son h3 et sa description.
- Le lien externe s’ouvre dans un nouvel onglet avec rel="noopener".
- Le contact utilise mailto et une adresse example.com.

## Exemple guidé 2

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ama Mensah — page personnelle</title>
</head>
<body>
  <main>
    <p>Mon quiz : <a href="https://github.com/exemple/quiz">voir le code du quiz de révision</a>.</p>
    <p>Mes autres projets sont <a href="#projets">dans la section Projets</a>.</p>
    <section id="projets"><h2>Projets</h2></section>
  </main>
</body>
</html>

```

Résultat attendu : Des liens dont le texte se comprend sans le reste de la phrase.

Trace :

- Le premier lien dit ce qu’on va voir.
- Le second annonce sa destination interne.
- Aucun « cliquez ici ».

## Vérifier et expliquer

Liste trois de tes projets, même petits, et écris pour chacun un titre, une phrase et le texte de son lien.
