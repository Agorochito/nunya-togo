## Explication pas à pas

Sur un téléphone, les cartes de projets s’empilent en une colonne. Sur un écran d’ordinateur, cette colonne devient étroite et longue, et l’espace sur les côtés reste vide. La grille CSS permet de passer à deux colonnes à partir d’un point de rupture : dans la requête média, grid-template-columns: 1fr 1fr crée deux colonnes de même largeur. L’unité fr signifie « une part de l’espace disponible » : deux colonnes de 1fr se partagent la place à égalité. On peut aussi écrire repeat(2, 1fr), qui donne le même résultat et se lit mieux quand les colonnes sont nombreuses.

Le contenu HTML ne change pas : ce sont les mêmes articles, dans le même ordre. Seule la disposition change. Cet ordre compte : un lecteur d’écran et un visiteur au clavier suivent l’ordre du code, pas l’ordre visuel. Évite donc de réordonner visuellement les cartes avec des propriétés comme order : ce qui paraît premier doit aussi être premier dans le code.

Parfois, un contenu n’a de sens que sur un grand écran. Une astuce qui parle de « passer la souris » ne concerne pas un écran tactile. On peut la masquer par défaut avec display: none, puis l’afficher dans la requête média avec display: block. display: none retire complètement l’élément : il n’est ni affiché ni lu par les lecteurs d’écran.

Utilise ce masquage avec prudence. Ne cache jamais une information importante sur téléphone : les visiteurs mobiles ont droit au même contenu essentiel. Le masquage est réservé au secondaire : une décoration, une astuce liée à la souris, une illustration qui encombrerait l’écran. Une bonne question à se poser : si ce contenu disparaissait aussi sur ordinateur, manquerait-il à quelqu’un ? Si oui, il ne doit pas disparaître sur téléphone.

Enfin, garde des espacements cohérents d’un écran à l’autre. On peut agrandir légèrement les marges sur grand écran, mais la logique reste la même : les valeurs de ton échelle d’espacements, par exemple 8, 16 et 32 pixels.

Teste chaque modification aux deux largeurs. Un changement qui embellit l’affichage sur ordinateur peut casser le téléphone, et inversement. Les exercices le font pour toi à 360 et 1 000 pixels.

## Exemple guidé 1

```html
<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ama Mensah — page personnelle</title>
  <style>
    .projets {
      display: grid;
      gap: 16px;
    }
    .astuce {
      display: none;
    }
    @media (min-width: 700px) {
      .projets {
        grid-template-columns: 1fr 1fr;
      }
      .astuce {
        display: block;
      }
    }
  </style>
</head>
<body>
  <main>
    <div class="projets">
      <article><h3>Quiz</h3></article>
      <article><h3>Club</h3></article>
    </div>
    <aside class="astuce"><p>Astuce : passe la souris sur une carte pour la mettre en valeur.</p></aside>
  </main>
</body>
</html>

```

Résultat attendu : Sur téléphone, une colonne de cartes et pas d’astuce ; sur ordinateur, deux colonnes et l’astuce visible.

Trace :

- La grille de base a une colonne.
- L’astuce est masquée par défaut.
- La requête média ajoute deux colonnes et affiche l’astuce.
