## Explication pas à pas

Les données ne sont pas toujours connues quand le programme est écrit. Dans cet atelier, input reçoit un message et rend la prochaine réponse préparée dans les saisies. Par exemple, input("Quantité ?") peut rendre la chaîne "4". Ce service est un auxiliaire pédagogique de Nunya. Ce n’est ni une fonction standard du langage JavaScript, ni la fenêtre prompt d’une page web. Le programme reste synchrone : il reçoit les réponses dans leur ordre.

Une réponse fournie par input est du texte, même si elle contient seulement des chiffres. Le signe + a un rôle particulier avec le texte : il peut concaténer, c’est-à-dire assembler. Ainsi "4" + "2" produit "42", tandis que 4 + 2 produit 6. La console peut montrer des caractères semblables dans plusieurs cas ; elle ne remplace donc pas l’examen des types.

Number transforme une valeur en nombre lorsque sa forme le permet. Number("4") donne 4 et Number("2.5") donne 2.5. Dans les saisies numériques de ce cours, le point sert de séparateur décimal. Le texte "deux" ne devient pas automatiquement 2 : la conversion donne NaN, une valeur qui indique un résultat numérique non valable. Les conditions du prochain module permettront de traiter ces situations.

Une chaîne vide demande aussi de l’attention. Number("") vaut zéro et ne prouve pas qu’une personne a réellement répondu zéro. La méthode trim retire les espaces au début et à la fin d’une chaîne. On peut donc conserver le texte nettoyé avant de le convertir. Cette étape servira à distinguer une absence de réponse d’un nombre saisi. Ne supprime pas le texte initial si le contrat demande de le garder.

String fait la conversion explicite dans l’autre sens. String(12) donne un texte que l’on peut intégrer à un message. Nous choisissons cette écriture claire plutôt que compter sur des conversions implicites. Pour un résultat annoncé avec une unité, construis le calcul avec des nombres, puis le message avec du texte. Cette séparation facilite la vérification des deux parties.

Prépare deux essais différents pour un même programme : ils doivent utiliser la saisie au lieu d’afficher un nombre appris par cœur. Écris les valeurs attendues avant l’exécution et garde les unités hors du calcul numérique. Ne demande aucune donnée personnelle réelle. Un prénom fictif, une quantité inventée ou une durée d’exercice suffisent pour apprendre la circulation des valeurs.

## Exemple guidé 1

```javascript
const texte = input("Quantité ?");
const quantite = Number(texte);
console.log(quantite + 2);
```


## Exemple guidé 2

```javascript
const mot = input("Nom fictif ?").trim();
console.log("Salut " + mot);
```
