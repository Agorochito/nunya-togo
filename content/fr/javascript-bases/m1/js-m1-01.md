## Explication pas à pas

Un programme est un texte d’instructions que le moteur JavaScript exécute. L’éditeur sert à changer ces instructions ; la console présente certains résultats. Les deux espaces ont des rôles différents. Modifier l’éditeur ne relance pas automatiquement le programme. Une console peut donc encore montrer la sortie de l’essai précédent. Pour comparer correctement, relance le code puis regarde le nouveau résultat.

console.log est la commande d’affichage utilisée dans ce cours. Écris ce nom avec cette casse, une parenthèse ouvrante, la valeur à montrer et une parenthèse fermante. Un point-virgule termine ici l’instruction. Nous conservons cette écriture régulière pour rendre les exemples faciles à lire. Une majuscule différente peut désigner un autre nom ; Console n’est pas console.

Un texte est une valeur appelée chaîne de caractères. Il s’écrit entre guillemets droits, simples ou doubles, qui doivent former une paire. Les guillemets délimitent le texte dans le programme ; ils ne sont pas affichés. Un nombre comme 12 peut être écrit sans guillemets. La console montre sa représentation, mais nous apprendrons bientôt que nombre et texte ne se comportent pas toujours pareil.

Le moteur suit les instructions dans leur ordre. Deux appels à console.log créent ici deux lignes. Pour annoncer une rencontre fictive, le titre peut venir avant le lieu. Inverser les instructions inverse les messages ; le moteur ne devine pas l’ordre que tu avais en tête. Avant d’exécuter, écris sur papier la sortie que tu prévois, puis compare chaque ligne.

Les espaces à l’intérieur d’un texte font partie du message. Ils peuvent expliquer une différence avec le résultat attendu. Les retours à la ligne du programme séparent les instructions, tandis que les retours de la console viennent des appels d’affichage. Un commentaire commençant par deux barres obliques explique le code pour le lecteur et n’est pas exécuté.

Dans l’atelier, tu peux relancer et corriger sans limite. Commence par une seule modification et garde un message court. Si le moteur signale une erreur, vérifie d’abord les noms, les parenthèses et les guillemets. Cette première pratique utilise uniquement la console : elle ne construit pas encore une page web et ne demande aucun compte ni service externe.

## Exemple guidé 1

```javascript
console.log("Bonjour");
```


## Exemple guidé 2

```javascript
console.log("Club lecture");
```
