## Explication pas à pas

Nous voulons maintenant garder une valeur pour la retrouver dans plusieurs instructions. Une variable associe un nom à cette valeur. La déclaration const places = 8 crée le nom places avec le nombre 8. Le signe égal indique une affectation : on calcule ce qui se trouve à droite, puis on associe le résultat au nom de gauche. Il ne pose pas une question d’égalité.

Le nom sert ensuite sans guillemets. console.log(places) lit la valeur de la variable, tandis que console.log("places") affiche le mot places. Choisis un nom qui décrit la donnée : prixUnitaire, nombreJours ou total. Évite un nom qui promet autre chose que son contenu. La casse compte toujours ; total et Total sont deux noms différents.

Nous utilisons const lorsque nous ne voulons pas réaffecter le nom. Si la valeur doit évoluer, let autorise une nouvelle affectation. Après let score = 2, écrire score = score + 1 lit d’abord 2, calcule 3 puis conserve 3. Il ne faut pas ajouter une nouvelle déclaration let au même endroit pour faire cette mise à jour.

JavaScript calcule avec les nombres : + additionne, - soustrait, * multiplie et / divise. Les multiplications et divisions passent avant les additions et soustractions. Des parenthèses expriment une autre priorité. Dans un budget fictif, quantité * prixUnitaire produit un montant ; (prix + frais) * quantité signifie que les frais sont appliqués à chaque unité. Les deux formules ne décrivent pas le même modèle.

Le résultat d’une opération peut lui-même être conservé dans une variable. Cela rend le programme lisible et facilite une trace. Note après chaque ligne les valeurs connues : prix, quantité puis total. Les noms ne se remplacent pas automatiquement par un nouveau calcul si une donnée change plus tard. Pour obtenir un autre total, il faut exécuter l’instruction de calcul correspondante.

Cette leçon travaille des valeurs numériques déjà écrites dans le programme. Nous ne lisons pas encore de saisie utilisateur. Les prix et quantités des activités sont fictifs ; le programme applique une règle fournie, sans déduire un tarif réel. Vérifie les unités sur papier et prédis au moins un résultat avant d’exécuter. Une formule correcte ne suffit pas si elle représente mal la consigne.

## Exemple guidé 1

```javascript
const prix = 150;
const quantite = 4;
const total = prix * quantite;
console.log(total);
```


## Exemple guidé 2

```javascript
let points = 3;
points = points + 2;
console.log(points);
```
