## Explication pas à pas

Le jardin calcule une réduction sur plusieurs montants fictifs. Recopier le calcul partout rend les corrections répétitives. Une fonction permet de nommer ce traitement et de l’appeler avec différentes valeurs. Une déclaration commence ici par function, un nom, des parenthèses contenant les paramètres, puis un bloc. Définir la fonction ne lance pas immédiatement le calcul de son corps. C’est un appel qui lui fournit les valeurs à traiter.

Un paramètre est un nom écrit dans la définition. Un argument est une valeur fournie lors d’un appel. Dans function doubler(nombre) { return nombre * 2; }, nombre est un paramètre. Dans doubler(4), quatre est un argument ; pendant cet appel, le paramètre reçoit cette valeur. Un autre appel peut lui fournir sept. L’ordre compte lorsque plusieurs paramètres existent : une fonction remise(montant, pourcentage) doit recevoir ces deux rôles dans l’ordre annoncé.

return termine l’exécution courante de la fonction et transmet une valeur à l’endroit de l’appel. Cette valeur peut être conservée, utilisée dans un autre calcul ou affichée. console.log produit un message pour le lecteur, mais ne remplace pas ce retour. Une fonction qui affiche un résultat sans le retourner ne permet pas de le réutiliser de la même manière. Sans return exécuté, le résultat d’un appel est undefined. Garde l’expression à retourner sur la même ligne que return dans nos exemples.

Les paramètres et les variables déclarées dans le corps appartiennent au contexte local de l’appel. Une variable locale peut porter un nom simple sans devenir une donnée partagée par tous les appels. Pour suivre une fonction, note ses arguments, les valeurs de ses paramètres, ses calculs et son retour. Une instruction après return dans le même chemin ne sera pas exécutée. Si une condition propose plusieurs chemins, chacun doit produire le résultat prévu par le contrat.

Le contrat précise les entrées autorisées et le résultat attendu. Notre réduction reçoit un montant fini non négatif et un pourcentage fini entre zéro et cent inclus. Elle retourne le montant diminué de la part retirée, sans affichage. Les entrées invalides sont exclues ici ; nous n’ajoutons pas une gestion d’erreurs non demandée. Les tests appellent la fonction avec plusieurs arguments, y compris zéro, cent et une valeur décimale. Une tolérance numérique annoncée évite de confondre une petite représentation flottante avec une mauvaise formule. Pour de l’argent réel, il faudrait choisir séparément une représentation et une règle d’arrondi.

## Exemple guidé 1

```javascript
function montantApresRemise(montant, pourcentage) {
  const partRetiree = montant * pourcentage / 100;
  return montant - partRetiree;
}
const resultat = montantApresRemise(80, 25);
console.log(resultat);
```

## Exemple guidé 2

```javascript
function afficherDouble(n) { console.log(n * 2); }
function retournerDouble(n) { return n * 2; }
const absent = afficherDouble(3);
const valeur = retournerDouble(3);
console.log(absent === undefined);
console.log(valeur + 1);
```
