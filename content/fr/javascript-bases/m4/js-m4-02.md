## Explication pas à pas

Nous savons parcourir des numéros avec for. Pour lire directement les éléments d’un tableau, for...of fournit successivement chaque valeur. Dans for (const valeur of valeurs), le nom valeur reçoit l’élément courant pour le bloc de ce passage. Ce nom n’est pas l’indice. Sur [8, 3, 5], la boucle reçoit huit, puis trois, puis cinq. L’ordre du tableau est conservé sans tri automatique.

Le const dans l’en-tête n’empêche pas le parcours : chaque passage dispose de sa liaison pour la valeur courante. Il évite une réaffectation inutile de ce nom dans le bloc. Le tableau lui-même reste une collection distincte. Pour ces exercices, nous ne changeons pas la collection pendant que nous la parcourons ; l’objectif est d’abord de comprendre quelles données sont lues et quels résultats sont construits séparément.

L’agrégation rassemble plusieurs valeurs dans un résultat. Une somme utilise un accumulateur initialisé à zéro avant la boucle. Un compteur peut compter les éléments qui satisfont une condition. Nous retrouvons les rôles du module précédent : total = total + valeur ajoute une donnée, tandis que nombre = nombre + 1 ajoute un événement. La longueur du tableau donne le nombre d’éléments présents ; elle ne donne pas leur somme.

Une sélection conserve certaines valeurs dans un nouveau tableau. On prépare resultat = [] avant le parcours. Pour chaque valeur, un if vérifie le critère ; push ajoute la valeur seulement si elle convient. Le tableau d’origine garde ainsi toutes ses données, tandis que resultat contient les éléments retenus dans leur ordre initial. Nous n’utilisons pas encore les méthodes à fonction de rappel : les conditions et les actions restent visibles ligne par ligne.

Le critère doit être précis. Une sélection de valeurs supérieures ou égales à cinq inclut cinq ; une sélection strictement supérieure ne l’inclut pas. Les doublons restent présents si le contrat ne demande pas de les retirer. Filtrer ne signifie ni trier ni compter des valeurs différentes. Une liste contenant deux fois sept peut donc conserver deux fois sept après sélection.

Un tableau vide produit zéro passage. Une somme reste alors zéro et une sélection reste vide. De même, un tableau non vide peut conduire à une sélection vide si aucun élément ne convient. Il faut traiter cette absence de résultat comme un cas normal. N’affiche pas un premier élément qui n’existe pas pour représenter artificiellement une réussite.

Dans l’atelier, certaines séries sont construites à partir d’un nombre annoncé de saisies. Le parcours de lecture et le parcours du tableau sont deux étapes distinctes, même s’ils utilisent tous deux une boucle. Trace d’abord la collection obtenue, puis le résultat partiel après chaque valeur. Teste un seuil qui retient tout, un seuil qui ne retient rien et une frontière exacte pour vérifier la règle sans dépendre d’un seul exemple.

## Exemple guidé 1

```javascript
const valeurs=[3,-1,4];
let total=0;
for(const valeur of valeurs){total=total+valeur;}
console.log(total);
```

Saisies scriptées : [].

Résultat attendu :

```text
6
```

Trace :

- Le tableau conserve 3, -1 et 4.
- total commence à 0, puis devient 3 après la première valeur.
- La valeur -1 donne total=2 et la valeur 4 donne total=6.
- La console affiche le total final, pas le nombre d’éléments.

## Exemple guidé 2

```javascript
const valeurs=[4,7,7,2];
const retenues=[];
for(const valeur of valeurs){if(valeur>=5){retenues.push(valeur);}}
console.log(retenues.length);
console.log(retenues[0]);
```

```text

```

- retenues commence vide.
- 4 est refusé ; chaque 7 est ajouté une fois.
- 2 est refusé ; retenues contient donc deux valeurs 7 dans l’ordre.
- La longueur vaut 2 et son premier élément vaut 7.
