## Explication pas à pas

Jusqu’ici, chaque valeur possédait son propre nom. Un tableau regroupe plusieurs valeurs dans un ordre. On l’écrit avec des crochets et des virgules : const villes = ["Kara", "Sokodé", "Lomé"]. Cette déclaration associe le nom villes à un tableau de trois chaînes. L’ordre est conservé ; le moteur ne trie pas les mots et ne les classe pas automatiquement par importance.

Chaque élément occupe une position appelée indice. Le premier indice est zéro, le deuxième est un et le troisième est deux. villes[1] lit donc Sokodé. Les crochets utilisés après le nom servent à demander une position ; ils ne créent pas ici un nouveau tableau. Écris les indices au-dessus des éléments lorsque tu traces un exemple. Cette habitude évite de confondre le rang courant et le nombre d’éléments.

La propriété length indique combien de positions contient le tableau. Pour trois éléments, length vaut trois, mais le dernier indice utilisable vaut deux. La relation dernier indice = length − 1 sert seulement si le tableau n’est pas vide. Un tableau vide s’écrit [] et sa longueur vaut zéro. Dans ce cas, il ne possède aucun premier ou dernier élément à afficher comme une valeur existante.

Lire une position absente produit undefined. Ce résultat signifie ici qu’aucune valeur n’a été obtenue à cette position ; ce n’est pas le texte "undefined" saisi par une personne. Avant un accès variable, vérifie que l’indice est entier, au moins zéro et strictement inférieur à length. Les conditions déjà étudiées permettent d’afficher un message explicite lorsqu’une position n’est pas autorisée, plutôt que d’interpréter une absence comme un élément réel.

On peut remplacer un élément avec une affectation telle que villes[0] = "Tsévié". La méthode push ajoute un élément à la fin et augmente la longueur. Nous travaillons des tableaux simples, sans trous ni indices sautés. Le mot const interdit de réaffecter le nom villes à un autre tableau, mais il n’interdit pas ces modifications du contenu. C’est une distinction entre le nom conservé et la collection qu’il désigne.

Un tableau peut être construit avec des saisies déjà connues : les réponses scriptées restent lues dans l’ordre avant leur rangement. Conserve des valeurs de même rôle dans les activités, par exemple une série de mots ou de nombres. Ce choix facilite la compréhension sans imposer que tous les tableaux du langage soient identiques. Teste la première position, la dernière et une position refusée. La réussite consiste à relier le tableau, sa longueur et l’indice demandé sans décalage caché.

## Exemple guidé 1

```javascript
const villes=["Kara","Sokodé","Lomé"];
console.log(villes[0]);
console.log(villes.length);
console.log(villes[villes.length-1]);
```

Résultat attendu :

```text
Kara
3
Lomé
```

Trace :

- La déclaration conserve trois chaînes dans l’ordre.
- L’indice 0 contient Kara et length vaut 3.
- Le dernier indice calculé vaut 3−1=2 ; la dernière ligne affiche Lomé.

## Exemple guidé 2

```javascript
const mots=["club","livre"];
mots[0]="atelier";
mots.push("lecture");
console.log(mots[0]);
console.log(mots.length);
```
