## Explication pas à pas

Une comparaison donne vrai ou faux ; une condition utilise ce résultat pour choisir une action. Le mot if signifie si. Il est suivi d’une expression entre parenthèses puis d’un bloc entre accolades. Quand le test est vrai, le moteur exécute ce bloc. Le mot else signifie sinon : son bloc est choisi lorsque le test est faux. Dans cette structure, les deux branches ne sont pas exécutées ensemble.

Les accolades délimitent les instructions de chaque branche. L’indentation, c’est-à-dire les espaces placés au début des lignes, aide le lecteur à les voir. Contrairement à certaines autres écritures, ces espaces ne remplacent pas les accolades JavaScript. Nous conservons les deux pour éviter les ambiguïtés. Une parenthèse ou une accolade oubliée peut empêcher l’ensemble du programme de démarrer.

Pour produire une valeur après le choix, on peut déclarer une variable avec let avant le if, puis l’affecter dans chaque branche. Le message est ensuite affiché une seule fois. Cela sépare décision et présentation. Déclarer une autre variable const message à l’intérieur de chaque bloc crée au contraire des noms locaux aux blocs ; ils ne sont pas automatiquement disponibles après les accolades.

Une condition ne valide que la règle écrite. Si tu convertis un mot avec Number, le résultat peut être NaN. Number.isFinite vérifie si la valeur est un nombre fini : elle renvoie un booléen. Le point fait partie du nom de ce service prédéfini. Tester seulement un seuil sur une conversion invalide ne signifie pas que l’entrée a été comprise ou acceptée correctement.

Nous allons donc écrire deux sortes de choix séparés dans les exercices : choisir un message à partir d’un seuil, puis reconnaître une conversion non finie. Le module suivant combinera plusieurs critères. Pour l’instant, lis une condition simple, indique quelle branche est prise et vérifie la valeur de la variable après ce passage. Les mots invalide ou disponible décrivent un état du scénario fictif.

Prépare au moins un exemple pour chaque branche. Un programme qui ne rencontre jamais else pendant les essais peut y cacher une erreur. Reviens aussi à la valeur limite vue dans la leçon précédente. L’objectif n’est pas de mémoriser une mise en page de code, mais de relier chaque condition à une règle exprimée en français et chaque sortie au cas réellement rencontré.

## Exemple guidé 1

```javascript
const places=0;
if (places===0) {
  console.log("Complet");
} else {
  console.log("Disponible");
}
```


## Exemple guidé 2

```javascript
const nombre=Number(input("Nombre ?"));
let message;
if (Number.isFinite(nombre)) { message="Valide"; }
else { message="Invalide"; }
console.log(message);
```
