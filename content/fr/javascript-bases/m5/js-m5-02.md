## Explication pas à pas

Le jardin prépare plusieurs ateliers. Un objet décrit une fiche ; un tableau rassemble ces fiches dans un ordre. Dans [{ id:"semis", places:4 }, { id:"compost", places:0 }], chaque élément est un objet. La lecture ateliers[0].places commence par choisir le premier élément, puis lit sa propriété. Un tableau vide reste une collection valide : il ne possède simplement aucune fiche à parcourir.

Une boucle for...of donne successivement accès aux éléments du tableau. À chaque tour, la variable de boucle désigne une fiche, pas sa position numérique. Tu peux donc lire atelier.places pour mettre à jour un total. Initialise ce total à zéro avant la boucle. Si le tableau est vide, aucun tour n’est exécuté et le total reste zéro. Cette valeur n’est pas une réparation improvisée : elle correspond à la somme d’aucune place disponible.

Sélectionner plusieurs fiches demande un autre résultat. Commence avec un nouveau tableau vide, puis ajoute avec push les fiches qui satisfont le test. Un filtre de disponibilité peut garder celles dont places > 0. Le résultat conserve l’ordre de parcours et peut être vide. Les objets ajoutés sont ici les mêmes fiches, avec des références partagées ; construire un nouveau tableau ne copie pas automatiquement chaque objet. Nous ne les modifions donc pas après cette sélection.

Une recherche ponctuelle vise au contraire une seule fiche. Dans nos données, chaque id est unique. Initialise trouve à null pour représenter l’absence de résultat, puis remplace cette valeur lorsque l’id correspond. null est une valeur explicite choisie pour ce contrat ; ce n’est pas une fiche et il ne faut pas lire trouve.titre avant d’avoir vérifié sa présence. La prochaine leçon développera cette précaution et les propriétés absentes.

Ne confonds pas recherche et sélection. La première demande « quelle fiche porte cet identifiant ? » ; la seconde demande « quelles fiches respectent ce critère ? ». Écris le type de résultat attendu avant la boucle : nombre, tableau ou fiche éventuellement absente. Les exercices inspectent ces valeurs en plus de la console. Prépare un cas sans correspondance et un cas sur la borne du critère. Dans cette leçon, nous écrivons les boucles explicitement : les méthodes à fonction de rappel seront étudiées après les bases des fonctions, pour que chaque étape reste explicable.

## Exemple guidé 1

```javascript
const ateliers = [{ id:"semis", places:4 }, { id:"compost", places:0 }];
let total = 0;
for (const atelier of ateliers) {
  total = total + atelier.places;
}
console.log(total);
```

## Exemple guidé 2

```javascript
const ateliers = [{ id:"semis", places:4 }, { id:"compost", places:0 }];
const disponibles = [];
for (const atelier of ateliers) {
  if (atelier.places > 0) { disponibles.push(atelier); }
}
console.log(disponibles.length);
let trouve = null;
for (const atelier of ateliers) {
  if (atelier.id === "compost") { trouve = atelier; }
}
console.log(trouve.id);
```
