## Explication pas à pas

Pendant longtemps, on reconnaissait un message frauduleux à ses fautes d’orthographe et à ses tournures maladroites. Les assistants d’IA ont fait disparaître ce signal : un fraudeur peut produire en quelques secondes un message parfaitement rédigé, personnalisé avec ton prénom, dans un français impeccable. Les outils de clonage de voix peuvent imiter la voix d’un proche à partir de quelques secondes d’enregistrement trouvées sur les réseaux sociaux. Les vidéos truquées, appelées hypertrucages ou deepfakes, montrent une personne connue disant ce qu’elle n’a jamais dit.

Les techniques changent, mais le scénario reste le même, et c’est lui qu’il faut reconnaître. Quatre signaux reviennent presque toujours. L’urgence : « immédiatement », « avant ce soir », « sinon ton compte sera fermé ». L’argent : une demande de transfert, de frais à payer, de dépôt mobile money. Le code : une demande de code de vérification, de mot de passe ou de code secret. Le secret : « n’en parle à personne ». S’y ajoutent souvent un lien raccourci qui cache la vraie adresse, ou un expéditeur inconnu qui se présente comme quelqu’un de connu.

Face à ces signaux, le réflexe décisif est la vérification par un autre canal. Si « ton cousin » t’appelle d’un nouveau numéro pour demander de l’argent en urgence, raccroche et rappelle-le sur son numéro habituel, ou demande à un autre membre de la famille. Si « ta banque » t’écrit, n’utilise pas le lien du message : ouvre toi-même l’application officielle. Certaines familles conviennent d’un mot de passe oral, connu d’elles seules, pour vérifier une demande inhabituelle au téléphone.

Un code de vérification reçu par SMS ne se donne jamais à personne : ni à un agent, ni à un ami, ni à un assistant. Aucun service légitime ne te le demandera. C’est souvent la dernière barrière avant le vol d’un compte de messagerie ou de mobile money.

Ces signaux peuvent être repérés automatiquement, comme dans le module 2. Un petit programme cherche des indices de chaque catégorie et calcule un niveau d’alerte. Il ne remplace pas ton jugement : un fraudeur habile évite les mots attendus, et un message légitime peut contenir le mot « urgent ». Mais il illustre une démarche défensive réelle : combiner plusieurs signaux plutôt que se fier à un seul.

En cas de doute ou d’arnaque, parle-en à un adulte de confiance, signale le message à la plateforme et, en cas de perte d’argent, contacte immédiatement l’opérateur ou la banque.

## Exemple guidé 1

```python
SIGNAUX = {
    "urgence": ["urgent", "immédiatement", "dernier délai"],
    "argent": ["envoie", "transfert", "mobile money", "frais"],
    "code": ["code", "mot de passe"],
    "lien": ["bit.ly", "cliquez"],
}


def signaux(message):
    texte = message.lower()
    return [nom for nom, indices in SIGNAUX.items() if any(i in texte for i in indices)]

print(signaux("URGENT : envoie le code reçu par SMS"))
print(signaux("On se retrouve au marché demain ?"))
```

Affichage attendu :

    ['urgence', 'argent', 'code']
    []

Trace :

- Trois catégories de signaux dans le premier message.
- Aucune dans le second.
- La rédaction parfaite ne change rien aux signaux.

## Exemple guidé 2

```python
SIGNAUX = {
    "urgence": ["urgent", "immédiatement", "dernier délai"],
    "argent": ["envoie", "transfert", "mobile money", "frais"],
    "code": ["code", "mot de passe"],
    "lien": ["bit.ly", "cliquez"],
}


def signaux(message):
    texte = message.lower()
    return [nom for nom, indices in SIGNAUX.items() if any(i in texte for i in indices)]

message = "Bonjour tonton, c’est Kossi. Mon téléphone est cassé, envoie 20 000 par mobile money immédiatement."
print(signaux(message))
print("Vérifier par un autre canal" if len(signaux(message)) >= 2 else "Rien de suspect")
```

Affichage attendu :

    ['urgence', 'argent']
    Vérifier par un autre canal

Trace :

- Le message se présente comme un proche.
- Urgence et argent : le scénario classique.
- Le réflexe : rappeler Kossi sur son numéro habituel.

Propose à ta famille un mot de passe oral pour vérifier une demande d’argent inhabituelle au téléphone.
