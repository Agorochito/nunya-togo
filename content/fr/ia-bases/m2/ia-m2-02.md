## Explication pas à pas

Les modèles vus jusqu’ici travaillent sur des nombres. Comment faire avec du texte ? La méthode la plus ancienne, et encore utile, s’appelle le sac de mots. On découpe le texte en mots, on oublie leur ordre, et on compte leurs apparitions. « Vous avez gagné, envoyez votre code » devient : vous 1, avez 1, gagné 1, envoyez 1, votre 1, code 1.

Le découpage demande quelques précautions. On met tout en minuscules, sinon « Gagné » et « gagné » seraient deux mots différents. On retire la ponctuation. En Python, une expression régulière fait ce travail : re.findall avec un motif de lettres, y compris les lettres accentuées du français, renvoie la liste des mots. Ce prétraitement compte autant que le modèle : une erreur ici fausse tout le reste.

Pour apprendre, on part d’exemples étiquetés : des arnaques et des messages normaux. On attribue à chaque mot un poids : plus 1 chaque fois qu’il apparaît dans une arnaque, moins 1 chaque fois qu’il apparaît dans un message normal. Après l’apprentissage, « gagné » et « code » ont un poids positif, « demain » et « marché » un poids négatif. Pour classer un nouveau message, on additionne les poids de ses mots : un score positif signale une arnaque probable.

Ce modèle est une version très simplifiée des filtres réels, qui utilisent des probabilités, comme le classifieur bayésien naïf, et des millions de messages. Le principe est le même : le modèle n’a reçu aucune règle sur les arnaques ; il a appris, à partir des exemples, quels mots les accompagnent.

Ses limites sont instructives. Il ignore l’ordre des mots : « ce n’est pas une arnaque » et « c’est une arnaque » se ressemblent beaucoup pour lui. Un mot jamais vu pendant l’apprentissage ne compte pas. Et les fraudeurs s’adaptent : ils écrivent « g@gné » ou glissent des mots rassurants pour faire baisser le score. Un filtre doit donc être réentraîné régulièrement sur des exemples récents.

Enfin, les exemples d’apprentissage contiennent du texte écrit par des personnes. Des messages réels peuvent contenir des informations privées : on les anonymise avant de s’en servir, en retirant noms, numéros et adresses. Le module 4 y reviendra.

## Exemple guidé 1

```python
import re


def mots(texte):
    return re.findall(r"[a-zàâçéèêëîïôûùüÿœ]+", texte.lower())

print(mots("Vous avez GAGNÉ ! Envoyez le code."))
```

Affichage attendu :

    ['vous', 'avez', 'gagné', 'envoyez', 'le', 'code']

Trace :

- Le texte est mis en minuscules.
- La ponctuation disparaît.
- Les lettres accentuées sont conservées.

## Exemple guidé 2

```python
import re


def mots(texte):
    return re.findall(r"[a-zàâçéèêëîïôûùüÿœ]+", texte.lower())


def apprendre(arnaques, normaux):
    poids = {}
    for texte in arnaques:
        for m in mots(texte):
            poids[m] = poids.get(m, 0) + 1
    for texte in normaux:
        for m in mots(texte):
            poids[m] = poids.get(m, 0) - 1
    return poids


def classer(poids, message):
    score = sum(poids.get(m, 0) for m in mots(message))
    return "arnaque" if score > 0 else "normal"

poids = apprendre(['Vous avez gagné un téléphone, envoyez votre code', 'Urgent : votre compte est bloqué, envoyez le code', 'Gagné ! Réclamez votre lot'], ['Rendez-vous demain au marché', 'Le cours de maths est déplacé à demain', 'Votre colis arrive demain au marché'])
print(poids["code"], poids["demain"])
print(classer(poids, "Envoyez vite votre code"))
print(classer(poids, "On se voit demain au marché"))
```

Affichage attendu :

    2 -3
    arnaque
    normal

Trace :

- « code » apparaît dans deux arnaques : poids 2.
- « demain » apparaît dans trois messages normaux : poids −3.
- Les scores classent correctement deux nouveaux messages.
