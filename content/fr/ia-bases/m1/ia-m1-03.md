## Explication pas à pas

Un modèle qui reproduit parfaitement ses exemples d’apprentissage n’a rien prouvé : il les a peut-être simplement mémorisés. Pour savoir s’il fonctionne vraiment, on garde de côté une partie des exemples étiquetés, souvent 20 à 30 %, qu’on ne lui montre pas pendant l’apprentissage. Ce sont les exemples de test. On compare ensuite ses prédictions sur ces exemples aux vraies étiquettes.

La mesure la plus simple est l’exactitude : la proportion de prédictions justes. Elle peut être trompeuse. Si seulement 5 % des messages sont des arnaques, un modèle qui répond toujours « normal » obtient 95 % d’exactitude… sans jamais détecter une seule arnaque. Il faut donc regarder le détail des erreurs.

Pour une question à deux réponses, on choisit une catégorie « positive », celle qu’on cherche à détecter, ici « arnaque ». Quatre cas sont possibles. Un vrai positif est une arnaque détectée. Un faux positif est un message normal pris à tort pour une arnaque. Un faux négatif est une arnaque qui passe inaperçue. Un vrai négatif est un message normal reconnu comme tel. Ces quatre nombres forment la matrice de confusion.

Deux mesures en découlent. La précision répond à « quand le modèle crie à l’arnaque, a-t-il raison ? » : vrais positifs divisés par tous les messages signalés. Le rappel répond à « parmi les vraies arnaques, combien en a-t-il trouvé ? » : vrais positifs divisés par toutes les vraies arnaques.

Ces deux erreurs n’ont pas le même coût, et le bon compromis dépend de la situation. Pour un filtre d’arnaques, un faux négatif peut coûter de l’argent à une famille, alors qu’un faux positif fait seulement manquer un message. Pour un test médical de dépistage, rater un malade est grave. Pour un système qui bloque un compte bancaire, un faux positif empêche quelqu’un de payer ses courses. Avant de dire qu’un modèle est « bon », il faut donc demander : bon pour qui, et quelles erreurs fait-il ?

Ces mesures s’appliquent à toutes les IA, y compris celles que tu utiliseras sans les construire. Quand une entreprise annonce « 99 % de réussite », demande sur quels exemples, quelle part de faux positifs et de faux négatifs, et pour quels groupes de personnes. Le module 3 montrera qu’un modèle peut être excellent en moyenne et très mauvais pour un groupe particulier.

## Exemple guidé 1

```python
predictions = ['arnaque', 'normal', 'arnaque', 'normal', 'normal', 'arnaque', 'normal', 'normal']
verites = ['arnaque', 'normal', 'normal', 'arnaque', 'normal', 'arnaque', 'normal', 'normal']
justes = sum(1 for p, v in zip(predictions, verites) if p == v)
print(justes, "sur", len(verites))
print(sum(1 for p, v in zip(predictions, verites) if p == "arnaque" and v != "arnaque"), "faux positif")
print(sum(1 for p, v in zip(predictions, verites) if p != "arnaque" and v == "arnaque"), "faux négatif")
```

Affichage attendu :

    6 sur 8
    1 faux positif
    1 faux négatif

Trace :

- Six prédictions sur huit sont justes.
- Un message normal a été signalé à tort.
- Une arnaque est passée inaperçue.

## Exemple guidé 2

```python
verites = ["normal"] * 19 + ["arnaque"]
predictions = ["normal"] * 20
print(sum(p == v for p, v in zip(predictions, verites)) / 20)
print(sum(1 for p, v in zip(predictions, verites) if p == v == "arnaque"), "arnaque détectée")
```

Affichage attendu :

    0.95
    0 arnaque détectée

Trace :

- Le modèle répond toujours « normal ».
- Il obtient 95 % d’exactitude.
- Il ne détecte pourtant aucune arnaque.
