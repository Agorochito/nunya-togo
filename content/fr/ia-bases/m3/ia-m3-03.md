## Explication pas à pas

Les assistants qui répondent en langage naturel, comme ceux qu’on trouve dans les applications de messagerie ou les moteurs de recherche, reposent sur des grands modèles de langage. Leur principe de base est surprenant de simplicité : à partir d’un début de texte, prédire le mot suivant, puis recommencer avec le texte prolongé, mot après mot.

On peut construire une version miniature de cette idée. Dans un texte d’apprentissage, on compte pour chaque mot les mots qui le suivent : après « le », on trouve « marché » deux fois, « soir » une fois, « vent » une fois. Ces paires de mots consécutifs s’appellent des bigrammes. Pour générer du texte, on part d’un mot, on choisit le suivant le plus fréquent, et on continue. Le résultat ressemble à la langue d’apprentissage, sans que le programme ait la moindre idée de ce qu’est un marché.

Les vrais modèles regardent des milliers de mots de contexte au lieu d’un seul, ont appris sur une immense quantité de textes et comptent des milliards de paramètres ajustés par un réseau de neurones. Leur langue est remarquablement fluide. Mais le principe reste le même : produire une suite plausible. Rien dans ce mécanisme ne vérifie que la suite est vraie.

D’où le phénomène des hallucinations : le modèle invente avec assurance une date, une citation, une référence de livre, un article de loi ou un résultat de calcul. La réponse a la forme d’une bonne réponse, sans en avoir le contenu. Le risque est plus élevé sur les sujets rares, récents ou locaux, comme un détail de l’histoire du Togo ou un horaire de bus, parce que le modèle a vu peu de textes à leur sujet.

Utiliser ces outils avec intelligence suppose quelques réflexes. Vérifier les faits importants dans une source fiable : un manuel, un site officiel, une personne compétente. Demander les sources, puis vérifier qu’elles existent vraiment : un modèle peut inventer des références. Ne pas lui confier de calculs importants sans les refaire. Garder la responsabilité de ce qu’on publie ou rend : un devoir copié d’un assistant reste ton devoir, avec ses erreurs.

Ces outils restent utiles pour reformuler, expliquer autrement une notion, proposer un plan ou relire un texte. Ils fonctionnent comme un camarade très cultivé mais parfois distrait : on l’écoute, puis on vérifie. Le module suivant montre aussi ce qu’il ne faut jamais leur confier.

## Exemple guidé 1

```python
import re


def mots(texte):
    return re.findall(r"[a-zàâçéèêëîïôûùüÿœ]+", texte.lower())


def suivants(texte):
    liste = mots(texte)
    table = {}
    for a, b in zip(liste, liste[1:]):
        table.setdefault(a, {})
        table[a][b] = table[a].get(b, 0) + 1
    return table

print(suivants("le marché ouvre le matin. le marché ferme le soir. le soir le vent souffle.")["le"])
```

Affichage attendu :

    {'marché': 2, 'matin': 1, 'soir': 2, 'vent': 1}

Trace :

- Après « le », on a vu « marché » deux fois et « soir » deux fois.
- Chaque paire de mots consécutifs est comptée.
- C’est toute la « connaissance » du modèle.

## Exemple guidé 2

```python
import re


def mots(texte):
    return re.findall(r"[a-zàâçéèêëîïôûùüÿœ]+", texte.lower())


def suivants(texte):
    liste = mots(texte)
    table = {}
    for a, b in zip(liste, liste[1:]):
        table.setdefault(a, {})
        table[a][b] = table[a].get(b, 0) + 1
    return table


def predire_suivant(table, mot):
    if mot not in table:
        return None
    options = table[mot]
    return max(options, key=options.get)


def generer(table, debut, n):
    phrase = [debut]
    for _ in range(n):
        suivant = predire_suivant(table, phrase[-1])
        if suivant is None:
            break
        phrase.append(suivant)
    return " ".join(phrase)

table = suivants("le marché ouvre le matin. le marché ferme le soir. le soir le vent souffle.")
print(generer(table, "le", 6))
```

Affichage attendu :

    le marché ouvre le marché ouvre le

Trace :

- Le modèle choisit toujours le mot suivant le plus fréquent.
- Il produit une phrase grammaticale en apparence.
- Elle tourne en rond et ne dit rien de vrai : un mini-exemple d’hallucination.
