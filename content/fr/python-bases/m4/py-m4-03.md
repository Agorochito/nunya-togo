## Explication pas à pas

La condition d’une boucle détermine normalement sa poursuite. Il arrive cependant qu’une information découverte pendant un passage nécessite d’arrêter immédiatement. Le mot-clé break permet de quitter la boucle qui le contient. Les instructions restantes de ce passage sont ignorées et le programme reprend après cette boucle. Une condition if peut décider du moment où break doit être exécuté.

Par exemple, tu peux lire plusieurs nombres et arrêter dès qu’une valeur négative apparaît. Si le test de négativité se trouve avant print, cette valeur d’arrêt n’est pas affichée. break ne ferme pas tout le programme : une instruction après la boucle peut encore afficher un bilan ou proposer une autre action. Dans cette leçon, nous travaillons avec une seule boucle à la fois pour suivre clairement son effet.

continue a un autre rôle. Il ignore la fin du passage courant, puis revient à la prochaine étape de la répétition. Dans une boucle for, la variable reçoit ensuite la valeur suivante. Cela permet par exemple de parcourir des nombres sans afficher trois : quand la valeur courante vaut trois, continue évite le print situé plus bas, mais les valeurs suivantes restent traitées.

Avec while, fais particulièrement attention à la mise à jour du compteur. Si continue est exécuté avant cette mise à jour, le compteur peut rester bloqué sur la même valeur. Pour éviter cela, organise le bloc de sorte que toutes les voies nécessaires fassent progresser la condition. Dessine le trajet du passage ignoré : c’est souvent lui qui révèle un risque de répétition sans fin.

Tu verras aussi l’écriture while True pour une répétition dont l’arrêt est contrôlé par un break. True étant toujours vrai, la condition seule ne termine jamais la boucle. Il faut donc que le programme rencontre réellement son signal d’arrêt. Utilise cette forme seulement lorsque tu sais expliquer ce qui déclenchera break. Dans les tests de saisie, fournis le signal attendu et vérifie qu’aucune ligne après lui n’est traitée dans la boucle.

## Exemple guidé 1

```python
for nombre in range(1, 6):
    if nombre == 3:
        break
    print(nombre)
print("Fin")
```

## Exemple guidé 2

```python
for nombre in range(1, 6):
    if nombre == 3:
        continue
    print(nombre)
```
