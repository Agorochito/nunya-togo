## Explication pas à pas

Le projet de cette leçon consiste à deviner un nombre fixé dans le programme. Nous choisissons sept pour pouvoir préparer des tests précis. Aucun nombre aléatoire n’est utilisé : ce sera une notion ultérieure. Le jeu est une simulation locale. Tu peux lire le secret dans le code, car l’objectif n’est pas de cacher réellement une information ; l’objectif est de programmer les règles et leur arrêt correctement.

Découpe le problème en petites étapes. Le programme reçoit une proposition entière et la compare au secret. Si elle est plus petite, il affiche un indice demandant une valeur plus grande. Si elle est plus grande, il demande une valeur plus petite. Si les deux valeurs sont égales, la partie est gagnée. Une chaîne if/elif/else permet d’obtenir exactement un de ces messages pour chaque proposition.

Ajoute ensuite un nombre limité d’essais. Un compteur démarre à zéro et augmente de un chaque fois qu’une proposition est lue. Une condition essais < 3 autorise encore une lecture tant que trois essais n’ont pas été utilisés. Fais la mise à jour au bon moment : le premier essai doit être compté comme un essai, et une proposition ne doit pas faire avancer le compteur de deux.

Pour arrêter dès la réussite, tu peux utiliser break ou conserver un booléen trouve qui devient True. Avec while essais < 3 and not trouve, deux conditions sont nécessaires pour continuer : il reste un essai et la réponse n’a pas encore été trouvée. Après la boucle, le booléen permet de distinguer une réussite d’une fin sans succès.

Prépare plusieurs scénarios avant de terminer : réussite au premier essai, réussite au troisième, trois réponses incorrectes et propositions situées des deux côtés du secret. Ces scénarios ne doivent pas demander une quatrième saisie. Vérifie aussi les messages et leur ordre. Le code final n’utilise que des notions déjà apprises ; tu peux donc raconter le rôle de chaque variable et expliquer, passage par passage, pourquoi la partie finit.

## Exemple guidé 1

```python
secret = 7
proposition = 4
if proposition < secret:
    print("Plus grand")
elif proposition > secret:
    print("Plus petit")
else:
    print("Trouvé")
```

## Exemple guidé 2

```python
secret = 7
trouve = False
for essai in range(3):
    proposition = int(input())
    if proposition == secret:
        trouve = True
        break
if trouve:
    print("Trouvé")
else:
    print("À réessayer")
```
