## Explication pas à pas

La boucle for est pratique quand une suite de valeurs décrit la répétition. Avec while, tu décris plutôt une condition à respecter pour continuer. Python examine cette condition avant chaque passage. Si elle est vraie, il exécute le bloc puis revient au test. Si elle est fausse, il ignore le bloc et continue après la boucle. Il peut donc y avoir zéro passage dès le départ.

Une boucle while doit pouvoir progresser vers son arrêt. Pour compter, on initialise une variable avant la boucle, on la teste dans la condition, puis on la met à jour dans le bloc. Si la variable ne change jamais alors que la condition est vraie, le même passage se répète sans fin. La limite de sécurité de l’éditeur peut arrêter ce programme, mais elle ne remplace pas une condition correcte.

Pour afficher les nombres de un à trois, on peut démarrer compteur à un, continuer tant que compteur <= 3, afficher le compteur et ajouter un. Après avoir affiché trois, la mise à jour produit quatre. Le prochain test est faux, donc la boucle se termine. Place la mise à jour dans le bloc : une ligne revenue au niveau du while ne s’exécuterait qu’après la boucle.

Une condition peut aussi dépendre des valeurs saisies. Pour lire des nombres jusqu’à zéro, on lit une première valeur avant la boucle, puis on continue tant que cette valeur est différente de zéro. Il faut relire une valeur à la fin de chaque passage. Zéro sert de signal d’arrêt, appelé sentinelle ; dans cet exemple, il n’est pas traité comme une donnée à afficher.

Pour préparer tes essais, note les valeurs successives de la variable testée et la raison exacte de l’arrêt. Fournis aussi la sentinelle quand un exercice attend plusieurs saisies. Si tu oublies cette dernière valeur, le programme attend encore une entrée ou signale que les entrées sont épuisées. Cette situation est différente d’un mauvais calcul : elle concerne le dialogue prévu entre le programme et ses données.

## Exemple guidé 1

```python
compteur = 1
while compteur <= 3:
    print(compteur)
    compteur = compteur + 1
```

## Exemple guidé 2

```python
nombre = int(input())
while nombre != 0:
    print(f"Reçu : {nombre}")
    nombre = int(input())
```
