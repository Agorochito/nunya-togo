## Explication pas à pas

Une boucle peut produire un bilan au lieu d’afficher chaque donnée séparément. Un accumulateur conserve un résultat qui évolue pendant les passages. Pour une somme, il commence généralement à zéro, puis chaque nouvelle valeur est ajoutée à ce total. Il faut le créer avant la boucle afin que les passages successifs retrouvent le résultat déjà construit.

L’instruction total = total + valeur se lit en deux temps. Python calcule d’abord la somme à droite avec l’ancien total, puis attribue ce résultat à la variable de gauche. Après avoir traité trois montants de deux, cinq et trois, les totaux successifs sont deux, sept et dix. Avec total = valeur, l’ancien résultat serait oublié à chaque tour et seul le dernier montant resterait.

Un compteur suit le même mécanisme, mais ajoute généralement un à chaque événement retenu. Pour compter les valeurs atteignant dix, initialise compteur à zéro, puis augmente-le seulement dans le bloc if valeur >= 10. Le nombre de passages et le nombre de valeurs retenues ne sont pas nécessairement égaux. Place donc l’incrément dans le bloc qui correspond réellement à ce que tu veux compter.

Après la boucle, le total et le compteur permettent d’autres calculs. Une moyenne est le total divisé par le nombre de valeurs traitées. Avant de diviser, vérifie qu’il existe au moins une valeur : diviser par zéro provoque une erreur. Dans les exercices, un message spécial décrit le cas sans donnée ; il vaut mieux afficher ce message que produire une moyenne inventée.

Pour contrôler un programme de bilan, fais un tableau de suivi sur papier avec une ligne par passage : valeur reçue, total avant, total après et compteur après. Choisis des entrées où les valeurs sont différentes ; répéter seulement des zéros peut cacher un total réinitialisé ou une affectation incorrecte. Vérifie aussi le cas sans donnée et celui où aucune valeur ne satisfait la condition de comptage. Le bilan final doit refléter les règles annoncées, pas simplement le dernier tour.

## Exemple guidé 1

```python
total = 0
for montant in range(1, 4):
    total = total + montant
print(total)
```

## Exemple guidé 2

```python
compteur = 0
for tour in range(3):
    valeur = int(input())
    if valeur >= 10:
        compteur = compteur + 1
print(compteur)
```
