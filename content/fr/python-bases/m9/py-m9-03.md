## Explication pas à pas

Une liste non vide ne permet pas de lire n’importe quelle position. Pour une longueur trois, les indices positifs ordinaires sont zéro, un et deux. Lire trois provoque une IndexError. Lorsque la position provient d’un argument, le contrat doit annoncer les indices acceptés. Dans cette leçon, les indices négatifs sont refusés volontairement, même si Python les autorise pour d’autres usages : nous voulons une sélection numérotée depuis le début.

Une protection vérifie i >= 0 and i < len(valeurs) avant l’accès. L’ordre d’écriture peut rendre la lecture plus facile : d’abord établir que l’indice est valide, puis lire valeurs[i]. N’effectue pas la lecture avant de tester. Le cas vide est couvert par la même comparaison, car aucun entier positif ou nul n’est inférieur à zéro.

Pour indiquer qu’aucun élément ne peut être fourni, le contrat choisit None. Cette valeur est différente de zéro et du texte vide, qui peuvent être des éléments légitimes d’une liste. Un appel qui retourne None ne signifie donc pas nécessairement que le programme est défectueux : cela peut être une réponse prévue. Le programme appelant doit l’interpréter selon la règle annoncée.

Le même principe sert pour une première ou une dernière valeur optionnelle. Avant une division par la longueur, il permet aussi de séparer le cas sans donnée. La moyenne d’une liste vide n’est pas définie par la formule somme divisée par zéro ; retourner None l’exprime ici sans inventer un résultat numérique. Les exercices ne demandent pas de capturer toutes les exceptions : ils évitent les opérations impossibles à partir des conditions déjà enseignées.

Les activités appliquent ces règles dans quatre situations complémentaires. La protection respecte un contrat d’indices positifs explicite. La borne égale à la longueur est invalide, même lorsque la liste contient déjà plusieurs éléments. L’absence de résultat ne doit pas être confondue avec un dernier élément nul. Les tests distinguent donc une collection vide d’une collection contenant zéro. La réponse None marque une moyenne non définie pour ce contrat. Une liste non vide, même de valeurs négatives ou nulles, conserve la formule normale du bilan. Un défaut d’une seule unité peut autoriser une lecture impossible. Tester l’indice exactement égal à la longueur met cette frontière en évidence avant tout accès.

Pour réparer un programme, garde une copie de l’idée de départ et formule une hypothèse précise. Modifie une seule cause à la fois, puis relance le cas qui révélait le problème. Rejoue aussi un ancien cas correct pour vérifier que la réparation ne le casse pas. Un résultat affiché sans message d’erreur peut encore être faux : les tests vérifient le besoin, pas seulement l’absence d’arrêt.

## Exemple guidé 1

```python
def lire(valeurs, i):
    if i >= 0 and i < len(valeurs):
        return valeurs[i]
    return None
print(lire([4, 8], 1))
print(lire([4, 8], 2))
```

## Exemple guidé 2

```python
def premier(valeurs):
    if len(valeurs) == 0:
        return None
    return valeurs[0]
print(premier([]))
print(premier([0]))
```
