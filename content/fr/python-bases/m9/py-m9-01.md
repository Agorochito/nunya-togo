## Explication pas à pas

Quand Python s’arrête, le dernier type d’erreur et le message donnent une première piste. Une erreur de syntaxe signifie que le programme ne peut pas être compris comme un programme valide. Une parenthèse non fermée, un deux-points oublié ou une indentation incohérente peuvent empêcher le démarrage. Le numéro de ligne indique l’endroit où le problème a été constaté ; son origine peut se trouver juste avant, par exemple dans une chaîne restée ouverte.

Une erreur de nom, NameError, arrive pendant l’exécution lorsqu’un nom utilisé n’est pas défini dans la portée accessible. Les différences de casse comptent : total et Total sont deux noms distincts. Lire une valeur avant de l’avoir créée produit aussi une erreur. Une variable locale d’une autre fonction n’est pas un moyen de transmettre un résultat : il faut utiliser le retour et l’associer à un nom dans l’appelant.

Commence par lire le code de haut en bas et repérer les ouvertures, fermetures et blocs. Pour les fonctions, identifie les paramètres puis chaque nom créé. Vérifie que chaque lecture se produit après une définition du même nom. Une correction doit conserver la règle du calcul : supprimer le print ou retourner toujours zéro pourrait supprimer l’erreur sans répondre au besoin.

Les exemples montrent des versions réparées afin de pouvoir les exécuter. Les exercices proposent un défaut précis et un contrat complet. Compare le message d’erreur avec l’emplacement de la cause, puis explique ce qui change dans le programme. Les tests vérifient également les résultats sur plusieurs arguments : une réparation réussie rétablit le comportement demandé, elle ne se contente pas de rendre le fichier acceptable pour Python.

Les activités appliquent ces règles dans quatre situations complémentaires. Une faute de syntaxe empêche tous les cas de démarrer. La réparation conserve la formule annoncée au lieu de contourner la fonction demandée. La cohérence d’un nom se vérifie caractère par caractère. Le résultat doit provenir de la somme locale, sans dépendre d’une variable extérieure au traitement. L’ordre d’exécution importe même quand toutes les lignes semblent présentes. Un retour effectué avant l’affectation ne peut pas utiliser la valeur que celle-ci aurait créée. L’indentation exprime la structure de décision en Python. Les trois signes possibles du nombre vérifient que la correction conserve les branches et leur frontière.

Pour réparer un programme, garde une copie de l’idée de départ et formule une hypothèse précise. Modifie une seule cause à la fois, puis relance le cas qui révélait le problème. Rejoue aussi un ancien cas correct pour vérifier que la réparation ne le casse pas. Un résultat affiché sans message d’erreur peut encore être faux : les tests vérifient le besoin, pas seulement l’absence d’arrêt.

## Exemple guidé 1

```python
def doubler(nombre):
    resultat = nombre * 2
    return resultat
print(doubler(4))
```

## Exemple guidé 2

```python
def prix_total(prix, nombre):
    total = prix * nombre
    return total
reponse = prix_total(3, 5)
print(reponse)
```
