## Explication pas à pas

Les mêmes caractères peuvent représenter des valeurs de types différents. Le texte "12" n’est pas l’entier 12. Une fonction qui reçoit un texte doit l’interpréter explicitement si son contrat demande un calcul numérique. int(texte) convient pour les représentations d’entiers comme "12" ou "-3". float(texte) convient pour une représentation décimale avec un point, comme "2.5". Une conversion ne doit pas être ajoutée seulement pour faire disparaître un message : elle doit correspondre au sens des données.

Une TypeError signale notamment une opération inadaptée aux types reçus. Ajouter directement le texte "12" et le nombre trois ne produit pas quinze. Multiplier ce texte par trois produit en revanche "121212" : l’opération existe, mais ne réalise pas le calcul voulu. C’est un exemple d’erreur logique liée aux types qui ne provoque pas d’arrêt.

Une ValueError peut apparaître quand une conversion est demandée au bon type d’objet mais que sa valeur n’a pas la représentation attendue. int("deux") ne peut pas interpréter ce mot. Dans cette leçon, les contrats garantissent des textes numériques valides : nous n’introduisons donc pas une gestion d’exceptions non enseignée. Les saisies arbitraires et leur traitement robuste feront partie du cours intermédiaire.

Distingue aussi résultat et présentation. Pour construire un message avec un nombre, str(nombre) peut produire le texte à assembler. Pour additionner des quantités, garder des nombres évite de confondre concaténation et somme. Écris à côté de chaque argument son type annoncé puis suis le type de chaque expression. Cette trace courte explique souvent une erreur plus vite que des modifications au hasard dans le code.

Les activités appliquent ces règles dans quatre situations complémentaires. Le contrat exclut les textes non numériques, mais inclut les signes valides. La conversion produit la quantité sur laquelle la somme peut réellement être calculée. Une expression peut s’exécuter sans être correcte : multiplier une chaîne répète ses caractères. Le test du type et du résultat distingue cette répétition du calcul demandé. Choisir float conserve la partie décimale demandée par le contrat. Les exercices n’inventent pas une règle d’arrondi et comparent les résultats avec une petite tolérance numérique. La conversion en texte est adaptée à la présentation et non au calcul. Le préfixe et son espace font partie du format annoncé au programme appelant.

Pour réparer un programme, garde une copie de l’idée de départ et formule une hypothèse précise. Modifie une seule cause à la fois, puis relance le cas qui révélait le problème. Rejoue aussi un ancien cas correct pour vérifier que la réparation ne le casse pas. Un résultat affiché sans message d’erreur peut encore être faux : les tests vérifient le besoin, pas seulement l’absence d’arrêt.

## Exemple guidé 1

```python
def ajouter_trois(texte):
    nombre = int(texte)
    return nombre + 3
print(ajouter_trois("12"))
```

## Exemple guidé 2

```python
def message(nombre):
    return "Places : " + str(nombre)
print(message(4))
```
