## Explication pas à pas

Une chaîne de caractères est une valeur textuelle, appelée str en Python. Elle peut contenir des lettres, des chiffres, des espaces ou des signes. Les guillemets délimitent la chaîne dans le code ; ils ne sont pas affichés automatiquement. Tu peux utiliser des guillemets doubles ou des apostrophes, à condition de refermer avec le même signe que celui du début. Pour écrire J’aime apprendre, des guillemets doubles permettent de garder l’apostrophe intérieure sans la confondre avec la fin du texte.

Le signe + rassemble deux chaînes : on appelle cela la concaténation. Avec depart = "Lomé" et arrivee = "Kara", depart + arrivee donne LoméKara. Python n’ajoute aucun espace ni tiret. Pour une pancarte lisible, écris depart + " - " + arrivee. Le morceau du milieu contient un espace, un tiret et un autre espace. Un affichage qui semble presque correct peut simplement manquer un de ces caractères. Compare donc le résultat caractère par caractère avant de modifier tout le programme.

Un nombre n’est pas une chaîne, même s’il s’affiche avec des chiffres. L’expression "Classe : " + 2 provoque une erreur de type : Python ne choisit pas à ta place entre un calcul et un assemblage de texte. Avec str(2), tu obtiens le texte "2" ; tu peux alors l’assembler avec une autre chaîne. Si niveau contient le nombre 2, utilise "Classe : " + str(niveau). La conversion sert ici à présenter une valeur, pas à changer la quantité qu’elle représente.

La fonction len() donne le nombre de caractères d’une chaîne dans les exemples simples de cette leçon. Pour "Lomé", elle donne 4 ; pour "Club Démo", elle donne 9, car l’espace compte aussi. Ne confonds pas longueur et nombre de mots. Le texte peut aussi contenir un retour à la ligne écrit \n dans le code : print("Afi\nKossi") affiche deux lignes. Garde les textes d’exercice courts, lisibles et fictifs. Un message bien construit nomme ce qu’il affiche et évite de demander au lecteur de deviner le rôle d’un nombre isolé.

## Exemple guidé 1

```python
depart = "Lomé"
arrivee = "Kara"
trajet = depart + " - " + arrivee
print(trajet)
```

## Exemple guidé 2

```python
niveau = 2
message = "Classe : " + str(niveau)
print(message)
print(len("Lomé"))
```
