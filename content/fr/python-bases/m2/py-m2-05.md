## Explication pas à pas

Jusqu’ici, les valeurs étaient écrites directement dans le code. La fonction input() permet de recevoir une saisie au moment de l’exécution. Quand Python rencontre cette instruction, il attend une ligne de texte. La personne la fournit, puis valide. La fonction renvoie cette ligne sous forme de chaîne. Avec prenom = input(), le nom prenom reçoit donc le texte saisi. Tu peux afficher une salutation en assemblant "Bonjour " et prenom, exactement comme avec les chaînes de la leçon précédente.

Dans l’atelier de Nunya, les tests fournissent les saisies dans leur ordre. Si un exemple indique les entrées Afi puis 3, le premier input() reçoit Afi et le deuxième reçoit le texte "3". Les entrées ne sont pas du code Python à exécuter : ne les écris pas entre guillemets dans le champ de saisie du test. Pour garder la sortie facile à comparer, nos programmes utilisent input() sans message dans ses parenthèses. La consigne de l’exercice nomme séparément ce qui doit être saisi.

Une suite de chiffres reste un texte après input(). Pour obtenir un entier, écris nombre = int(input()). Python appelle d’abord input(), puis passe le texte obtenu à int(). Tu peux aussi séparer les opérations : saisie = input(), puis nombre = int(saisie). Cette seconde forme est utile pour suivre les types sur papier. Pour une mesure décimale, float(input()) joue le même rôle avec une représentation à point. Choisis le type selon le sens de la donnée, pas seulement selon son apparence.

La conversion ne valide pas toutes les intentions possibles. int("trois") et int("") échouent : le programme ne peut pas deviner un nombre. La saisie "2,5" ne convient pas à float() dans nos tests ; il faut "2.5". Les exercices de cette leçon annoncent des entrées valides pour apprendre la lecture et la conversion. Plus tard, tu apprendras à traiter les saisies incorrectes sans bloquer le programme. Pour l’instant, distingue toujours les trois moments : recevoir une chaîne, la convertir si nécessaire, puis afficher ou conserver le résultat. N’utilise ni coordonnées privées ni vrai secret comme donnée de test.

## Exemple guidé 1

```python
prenom = input()
message = "Bonjour " + prenom
print(message)
```

## Exemple guidé 2

```python
saisie = input()
places = int(saisie)
print(places)
mesure = float(input())
print(mesure)
```
