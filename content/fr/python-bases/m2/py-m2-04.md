## Explication pas à pas

Un booléen est une valeur qui représente vrai ou faux. Python écrit ces deux valeurs True et False, avec une majuscule initiale et sans guillemets. La ligne disponible = True associe un booléen à disponible. Avec print(disponible), le résultat affiché est True. Ce programme garde un état ; il ne prend pas encore de décision qui change l’ordre des instructions. Nous apprendrons plus tard à faire exécuter une partie du programme seulement lorsqu’une condition est vraie.

Les guillemets restent importants : "False" est un texte, pas le booléen False. Pour l’instant, ne cherche pas à convertir automatiquement un texte en booléen. Déclare directement la valeur qui correspond au scénario fictif. Un nom clair facilite la lecture : inscription_ouverte ou livre_disponible exprime une question dont la réponse peut être vraie ou fausse. Évite les noms ambigus comme chose, car ils obligent à relire tout le programme pour comprendre ce que représente l’état.

Une comparaison calcule aussi un booléen. Le signe == pose une question d’égalité ; il est différent du signe = qui affecte une valeur. Avec places = 3, puis print(places == 3), Python affiche True. Le signe != demande si les valeurs sont différentes. Les signes > et < comparent strictement ; >= et <= incluent aussi l’égalité. Pour une règle « au moins trois places », 3 >= 3 vaut True, alors que 3 > 3 vaut False. Lis le sens exact de la règle avant de choisir le signe.

On peut conserver le résultat d’une comparaison dans une variable : assez_de_places = places >= 3. Python lit d’abord la comparaison située à droite, puis associe son résultat au nom de gauche. Tu peux ensuite afficher ce résultat pour vérifier ton raisonnement. Les exemples comparent des nombres simples de même nature ; ne confonds pas le texte "3" et le nombre 3. Avant chaque exécution, prédis True ou False sur papier, puis justifie la réponse avec les données. Un résultat inattendu se corrige en relisant la question, les types et le signe utilisé, pas en changeant le résultat affiché à la main.

## Exemple guidé 1

```python
livre_disponible = True
print(livre_disponible)
livre_disponible = False
print(livre_disponible)
```

## Exemple guidé 2

```python
places = 3
assez_de_places = places >= 3
print(assez_de_places)
print(places > 3)
```
