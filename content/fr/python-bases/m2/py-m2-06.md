## Explication pas à pas

Les opérateurs arithmétiques permettent de calculer avec des nombres. Le signe + additionne, - soustrait et * multiplie. Avec prix = 250 et quantite = 4, prix * quantite donne 1000. Ici, ce sont des entiers ; le signe + ne joue donc pas le rôle de concaténation vu avec deux chaînes. Le type des valeurs compte. Lorsque les nombres viennent d’input(), convertis-les avant de calculer : autrement, une addition de deux textes peut simplement assembler leurs caractères.

Le signe / effectue une division et donne un résultat de type float dans nos exemples. Ainsi, 7 / 2 produit 3.5 et 8 / 2 produit 4.0. Le signe // calcule un quotient arrondi vers le bas. Pour des quantités positives, 17 // 5 donne 3 lots complets. Le signe % donne le reste : 17 % 5 vaut 2. On retrouve 17 avec trois lots de cinq et deux éléments restants. Les tests de partage de cette leçon emploient des quantités positives et un diviseur strictement positif.

Ne décris pas // comme une simple suppression des décimales dans tous les cas. Avec des valeurs négatives, arrondir vers le bas et aller vers zéro diffèrent : -7 // 2 donne -4, tandis que int(-7 / 2) donne -3. Pour débuter, observe surtout la question posée et les données autorisées. Aucune division par zéro n’est définie ici : /, // et % nécessitent un second nombre non nul. Les consignes garantissent cette condition dans les tests ; le traitement des saisies impossibles viendra plus tard.

Le signe ** représente une puissance : 3 ** 2 vaut 9. L’ordre des opérations ressemble aux priorités habituelles, mais les parenthèses évitent de dépendre d’une lecture implicite. Compare (2 + 3) * 4, qui vaut 20, à 2 + 3 * 4, qui vaut 14. Avant de coder, écris le calcul et son unité : total en FCFA, moyenne en éléments ou reste en cahiers. Ensuite, teste un petit exemple connu. Le résultat attendu doit découler des entrées, pas être recopié comme une constante qui ne fonctionnerait que pour un seul essai.

## Exemple guidé 1

```python
prix = 250
quantite = 4
total = prix * quantite
print(total)
print((2 + 3) * 4)
```

## Exemple guidé 2

```python
cahiers = 17
par_lot = 5
print(cahiers // par_lot)
print(cahiers % par_lot)
print(7 / 2)
print(3 ** 2)
```
