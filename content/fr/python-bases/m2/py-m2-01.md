## Explication pas à pas

Une variable permet de conserver une valeur sous un nom pour la retrouver plus tard dans le programme. Écris prenom = "Afi" : Python évalue la valeur à droite du signe égal, puis associe le nom prenom à cette valeur. Cette ligne n’affiche rien. Pour voir la valeur, ajoute print(prenom) sur la ligne suivante. Les guillemets entourent le texte Afi, mais pas le nom de la variable utilisé dans print. Tu disposes maintenant de deux opérations distinctes : attribuer une valeur, puis demander son affichage.

Le signe = est une affectation. Il ne demande pas si deux éléments sont égaux comme dans une question de mathématiques. Lis la ligne de droite à gauche : « prendre cette valeur et la ranger sous ce nom ». Une nouvelle affectation au même nom remplace l’association précédente. Avec stock = 12, puis stock = 9, un print(stock) placé après ces deux lignes affiche 9. Si tu places aussi un affichage entre elles, tu verras d’abord 12, puis 9. L’ordre d’exécution explique le résultat.

Choisis des noms qui décrivent ce que tu gardes : prenom, stock ou nom_du_club. Un nom peut contenir des lettres, des chiffres et le caractère de soulignement, mais il ne doit pas commencer par un chiffre. Évite les espaces. Python distingue les majuscules et minuscules : stock et Stock sont deux noms différents. Pour ces premiers exercices, garde des noms courts en minuscules et utilise le soulignement pour séparer plusieurs mots. Cette habitude réduit les erreurs de lecture.

Avant de lancer un programme, trace les valeurs sur papier. Pour chaque affectation, note le nom et sa nouvelle valeur ; pour chaque print, note ce qui doit apparaître à cet instant. Si Python indique qu’un nom n’existe pas, regarde si sa première affectation se trouve avant son utilisation et si son orthographe est identique. Un nom bien choisi n’est pas une protection de secret : n’utilise jamais un vrai mot de passe dans les exercices. Ici, des prénoms et quantités fictifs suffisent pour apprendre.

## Exemple guidé 1

```python
prenom = "Afi"
print(prenom)
```

## Exemple guidé 2

```python
stock = 12
print(stock)
stock = 9
print(stock)
```
