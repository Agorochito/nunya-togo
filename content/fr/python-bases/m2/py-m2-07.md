## Explication pas à pas

Une f-string est une chaîne précédée de la lettre f. Elle contient des accolades dans lesquelles Python évalue des noms ou des expressions. Avec prenom = "Afi", print(f"Bonjour {prenom}") affiche Bonjour Afi. Les accolades ne sont pas imprimées : leur contenu est remplacé par la représentation de la valeur. Sans la lettre f avant le guillemet, le texte {prenom} reste écrit tel quel. La différence tient à un seul caractère, mais elle change le sens du message.

Tu peux insérer un entier ou un décimal sans écrire str() autour de chaque valeur. Avec quantite = 3 et prix = 250, le texte f"Total : {quantite * prix} FCFA" contient le résultat du produit. Pour un message plus facile à relire, calcule d’abord total = quantite * prix, puis utilise {total}. Le programme garde ainsi une étape de calcul identifiable avant l’étape de présentation. N’inclus aucun vrai secret dans un message que le programme affiche ou conserve.

Le format :.2f demande deux chiffres après le point dans l’affichage. Avec montant = 2.5, f"{montant:.2f}" produit le texte 2.50. Cette présentation ne change pas la valeur stockée dans montant. Elle ne transforme pas non plus le point en virgule : les tests de cette leçon attendent le point. Un arrondi d’affichage ne remplace pas une méthode adaptée à de vrais calculs comptables. Ici, nous apprenons à présenter des résultats numériques simples avec des données de formation.

Pour le mini-projet, inventons la monnaie pédagogique TST. Le taux fixé uniquement pour l’exercice est 1 TST pour 500 FCFA. Ce taux n’est pas un cours réel, et TST n’est pas une monnaie à acheter ou à transférer. Lis un montant fictif en FCFA avec float(input()), divise-le par 500, puis affiche le résultat à deux décimales suivi de TST (taux fictif). Avec 750 FCFA d’exercice, tu obtiens 1.50 TST. Teste aussi zéro et un autre montant. Explique la chaîne complète : texte saisi, conversion en nombre, division par le taux fictif, puis création du message. Cette preuve montre une technique de programmation, pas un conseil de change.

## Exemple guidé 1

```python
prenom = "Afi"
quantite = 3
print(f"Bonjour {prenom}, quantité : {quantite}")
```

## Exemple guidé 2

```python
montant_fcfa = float(input())
taux_fictif = 500
montant_tst = montant_fcfa / taux_fictif
print(f"{montant_tst:.2f} TST (taux fictif)")
```
