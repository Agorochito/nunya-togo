## Explication pas à pas

Un entier représente une valeur sans partie décimale : 0, 12 et -3 sont des exemples. Python appelle ce type int. Un nombre écrit avec un point décimal, comme 2.5 ou 12.0, appartient généralement au type float. Pour saisir un tel nombre dans le code, utilise le point, même si tu écris habituellement une virgule en français. La valeur 2,5 ne signifie pas le nombre décimal 2.5 dans une instruction Python. Les quantités de ce cours sont des exemples pédagogiques, pas des données financières réelles.

Les guillemets changent la nature de la valeur. La valeur "12" est un texte qui contient deux caractères ; 12 est un entier. Tu peux afficher les deux et obtenir visuellement les mêmes chiffres. L’affichage seul ne suffit donc pas à déterminer ce que le programme peut en faire. La fonction int() convertit une représentation entière valide : int("12") produit l’entier 12. Garde le résultat dans une variable, par exemple quantite = int("12"), puis affiche quantite pour suivre ce qui a été obtenu.

La fonction float() interprète une représentation décimale valide. Avec distance = float("2.75"), distance reçoit un nombre décimal. Le texte doit employer le point : float("2,75") échoue au lieu de deviner la convention souhaitée. De même, int("2.75") échoue, car ce texte ne représente pas directement un entier. Ne corrige pas une erreur en supprimant au hasard des caractères : choisis le type correspondant à ce que mesure la donnée et lis la représentation attendue.

Il est aussi possible d’appliquer int() à un nombre décimal déjà interprété : int(3.9) donne 3. La partie décimale est retirée en allant vers zéro ; ce n’est pas un arrondi au plus proche. Pour int(-3.9), le résultat est -3. Un float peut afficher 5.0 plutôt que 5.00 : l’apparence du nombre ne conserve pas automatiquement le nombre de décimales que tu avais écrit. Plus tard, les chaînes formatées permettront de choisir un affichage. Pour l’instant, annonce le type voulu, vérifie l’écriture de l’entrée et compare le résultat attendu à la conversion réellement utilisée.

## Exemple guidé 1

```python
texte = "17"
quantite = int(texte)
print(quantite)
```

## Exemple guidé 2

```python
distance = float("2.75")
print(distance)
partie_entiere = int(3.9)
print(partie_entiere)
```
