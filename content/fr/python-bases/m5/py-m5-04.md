## Explication pas à pas

Une boucle for peut parcourir directement les éléments d’une liste : for nom in noms fournit successivement chaque nom. Il n’est pas nécessaire de calculer un indice si l’on veut seulement lire les valeurs. Pour préparer une liste de participants fictifs, nous pouvons nettoyer chaque réponse, puis conserver uniquement les textes non vides dans une nouvelle liste. Le test if propre != "" décide de l’ajout, mais ne change pas les réponses originales.

Un filtrage construit une sélection. Initialise selection = [], parcours les éléments, vérifie la condition et utilise append seulement lorsque cette condition est vraie. Les éléments retenus gardent leur ordre relatif et leurs répétitions. Le cas sans résultat est normal : la nouvelle liste reste vide. Pour additionner des nombres retenus, le mécanisme de compteur et de total étudié avec les boucles reste applicable.

Attention aux noms qui désignent le même objet. Après copie = valeurs, les deux noms retrouvent la même liste. Une modification par copie sera visible à travers valeurs. Pour fabriquer une autre liste contenant les mêmes éléments, utilise valeurs[:]. Tu peux alors ajouter une valeur à la copie sans allonger la liste initiale. Cette copie est dite superficielle : lorsque les éléments sont eux-mêmes des objets modifiables, leurs objets intérieurs restent partagés. Nos exemples utilisent seulement des nombres et des textes.

Évite de retirer des éléments de la liste que tu es en train de parcourir : les positions se déplacent et certaines valeurs peuvent être sautées. Construire une nouvelle sélection rend le raisonnement plus clair. Sépare aussi le nettoyage et la décision quand cela aide à tracer le programme : la variable propre permet de voir exactement quelle valeur est comparée, puis ajoutée.

Les activités appliquent ces règles dans quatre situations complémentaires. Nettoyer avant de filtrer permet de reconnaître les réponses seulement composées d’espaces. L’ordre des réponses utiles et leurs éventuelles répétitions restent conservés. Le filtrage respecte une frontière précise : zéro est exclu. Deux valeurs identiques restent deux éléments, car aucune déduplication n’est demandée. La copie superficielle suffit lorsque les éléments sont des nombres. Elle protège ici la longueur et les valeurs de la liste initiale contre l’ajout. Le bilan reprend le même critère de sélection que la liste filtrée. Le total additionne les valeurs retenues tandis que le compteur mesure combien elles sont.

Pour contrôler ce travail, écris d’abord les caractères ou les éléments dans leur ordre et numérote les positions à partir de zéro. Prévois le résultat avant de lancer l’exemple. Compare ensuite chaque modification avec la donnée initiale : lire, fabriquer une nouvelle valeur et modifier une liste sont trois actions différentes. Les données utilisées ici sont fictives ; leur seule fonction est de rendre les résultats faciles à vérifier.

## Exemple guidé 1

```python
noms = [" Awa ", " ", "Lina"]
selection = []
for nom in noms:
    propre = nom.strip()
    if propre != "":
        selection.append(propre)
print(selection)
```

## Exemple guidé 2

```python
valeurs = [2, 5]
copie = valeurs[:]
copie.append(8)
print(valeurs)
print(copie)
```
