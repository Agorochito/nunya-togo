## Explication pas à pas

L’autonomie ne signifie pas écrire sans aide à toute vitesse. Elle consiste à organiser une résolution et à savoir justifier les décisions prises. La variante de ce chapitre prépare un budget fictif d’atelier. Chaque ligne est un dictionnaire contenant nom, prix et nombre. Les prix sont numériques positifs ou nuls et les nombres sont des entiers positifs ou nuls. Aucun taux réel, paiement ou conseil financier n’est utilisé.

Le coût d’une ligne est prix multiplié par nombre. Le coût total additionne ces produits. Compter seulement les lignes répondrait à une autre question ; additionner seulement les prix oublierait les quantités. Une liste vide coûte zéro dans ce modèle. Les arguments restent intacts afin que l’appelant puisse calculer plusieurs scénarios à partir des mêmes lignes.

Pour vérifier si le budget suffit, compare le total au budget avec une borne incluse : une égalité exacte est autorisée. Une projection peut également retourner le montant restant ou le manque. Annonce le signe choisi pour éviter de mélanger une somme négative disponible et un manque positif. Les exercices utilisent des retours numériques explicites et une petite tolérance pour les calculs décimaux.

Explique ensuite ton choix de représentation. La liste conserve les lignes, le dictionnaire nomme les propriétés et la fonction sépare le calcul de sa présentation. Un ajout de frais fixes représente une règle distincte de celle des articles. Les frais ne doivent pas être multipliés par le nombre de lignes. Écris un cas contenant des quantités différentes pour contrôler cette distinction. La validation automatique compare les comportements ; ton explication personnelle doit aussi montrer que tu comprends pourquoi ils répondent au besoin.

Les activités appliquent ces règles dans quatre situations complémentaires. Un budget de lignes demande une somme de produits. Des quantités différentes révèlent une solution qui additionnerait seulement les prix ou le nombre de fiches. Une borne inclusive permet de dépenser exactement le budget fictif. Le cas zéro et le dépassement voisin contrôlent la décision sans introduire de règle financière réelle. Le signe est une règle de présentation du bilan. Une différence négative exprimerait autre chose que le manque positif demandé et ne devrait pas être transmise sous le même nom. Un coût fixe s’ajoute une fois, même sans ligne d’article dans ce contrat. Deux lignes permettent de détecter des frais répétés à tort à chaque passage.

Ce bilan sert à vérifier un transfert, pas à mesurer ta valeur ni à promettre une maîtrise professionnelle. Explique une solution avec un exemple, puis traite une variante sans regarder la correction. Les erreurs indiquent les notions à reprendre. Tu peux relire les modules utiles et recommencer les activités. Les données sont fictives et les résultats restent locaux ; aucune note officielle ni certification extérieure n’est attribuée par ces exercices.

## Exemple guidé 1

```python
def cout_total(lignes):
    total = 0
    for ligne in lignes:
        total = total + ligne["prix"] * ligne["nombre"]
    return total
print(cout_total([{ "nom":"papier", "prix":2, "nombre":3 }, { "nom":"crayon", "prix":1, "nombre":4 }]))
```

def budget_suffit(total, budget):
