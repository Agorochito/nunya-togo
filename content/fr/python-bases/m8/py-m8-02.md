## Explication pas à pas

Avant de choisir une boucle, prépare des exemples dont tu connais la réponse. Pour compter les quantités dépassant un seuil, la liste [2, 8, 8] avec un seuil huit doit donner deux si l’égalité est acceptée. Une liste vide doit donner zéro. Un cas où tout est inférieur vérifie encore une autre situation. Ces exemples sont des outils de raisonnement ; ils ne remplacent pas le contrat général.

Une trace décrit les valeurs à chaque étape. Dans le compteur, on note la valeur courante, le résultat de la comparaison et le compteur après la décision. Avec [2, 8, 8], les compteurs successifs sont zéro, un et deux. Si le compteur est remis à zéro à chaque passage, la trace montre exactement où le travail précédent est perdu. La dernière ligne seule ne permettrait pas d’expliquer le défaut.

Pour une recherche, choisis aussi la règle d’arrêt. Nous allons chercher si une valeur est présente : dès qu’une égalité est trouvée, return True peut terminer la fonction. Si le parcours finit sans égalité, return False est placé après la boucle. Le placer dans le else du premier passage ferait conclure trop tôt. Une valeur recherchée en dernière position est donc un cas particulièrement utile.

Les petits exemples réduisent l’effort de suivi. Commence par zéro, un ou deux éléments, puis augmente la taille lorsque les règles sont claires. Ne teste pas uniquement des valeurs identiques ou des zéros : ils peuvent masquer une somme incorrecte ou un ordre oublié. Une trace n’a pas à recopier chaque détail du langage ; elle doit rendre visible l’état qui détermine le résultat et permettre de relier une erreur à une étape précise.

Les activités appliquent ces règles dans quatre situations complémentaires. Des valeurs situées de part et d’autre du seuil rendent la décision visible. Le cas égal au seuil vérifie que la frontière annoncée est respectée. Un retour trop tôt oublierait les éléments suivants. La recherche doit permettre à une occurrence située en dernière position de produire le même succès qu’en première. Un mélange de signes révèle si le filtre et l’accumulateur jouent bien leurs rôles. La sortie n’est ni la dernière valeur ni le nombre de valeurs retenues. La paire conserve deux mesures différentes et dans un ordre annoncé. Le vérificateur compare ses éléments ; une liste équivalente est aussi acceptée pour cette activité.

Écris tes prévisions avant de consulter les résultats. Pour chaque cas, note les entrées, les étapes utiles et la réponse attendue. Choisis aussi une entrée différente de celles de l’exemple guidé. Si une règle manque dans une consigne réelle, il faut la clarifier plutôt que deviner ; ici, les contrats précisent les limites. Une solution courte et explicable vaut mieux qu’une accumulation de conditions sans lien avec le besoin.

## Exemple guidé 1

```python
def compter(valeurs, seuil):
    nombre = 0
    for valeur in valeurs:
        if valeur >= seuil:
            nombre = nombre + 1
    return nombre
print(compter([2, 8, 8], 8))
```

## Exemple guidé 2

```python
def contient(valeurs, cible):
    for valeur in valeurs:
        if valeur == cible:
            return True
    return False
print(contient([1, 4], 4))
print(contient([], 4))
```
