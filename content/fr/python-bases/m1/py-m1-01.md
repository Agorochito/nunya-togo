## Explication pas à pas

Tu n’as pas besoin d’avoir déjà programmé. Un programme est un texte qui donne des instructions à un ordinateur. Une instruction est une action écrite de façon précise. L’ordinateur ne devine pas ton intention : il applique ce que tu as écrit. Programmer consiste donc à décrire une action, observer le résultat et ajuster les instructions quand ce résultat n’est pas celui souhaité.

Dans cette page, deux espaces ont des rôles différents. L’éditeur est la zone où tu écris le programme. La console est la zone où tu lis ce que le programme affiche. Modifier le texte dans l’éditeur ne change pas automatiquement la console. Il faut demander une exécution, c’est-à-dire faire lire et appliquer les instructions par Python. Python est le langage de programmation utilisé dans ce cours : il possède des mots et des signes précis.

Nous commençons avec print. Ce nom anglais signifie « afficher » dans notre contexte. L’écriture print("Bonjour") demande d’afficher Bonjour. Les parenthèses ouvrante et fermante encadrent ce que l’on donne à print. Les guillemets droits encadrent un texte. Ils font partie du programme, mais ils ne font pas partie du message affiché. Garde cette différence en tête quand tu compares le code et son résultat.

Lis d’abord l’exemple guidé. Imagine ce qui doit apparaître, puis regarde la trace : elle raconte ce que l’ordinateur fait. Écris ensuite ton propre essai dans l’éditeur de l’exercice. Le bouton de vérification lance Python sur ton appareil et compare le résultat à la consigne. Une réponse incorrecte n’envoie aucune candidature, ne coûte aucun point et peut être réessayée.

Si le moteur Python ne peut pas démarrer, tu peux quand même lire les exemples, leurs traces et le quiz. La première exécution charge le moteur ; ensuite, l’option hors ligne permet de le conserver. Tu apprendras plus tard à retenir des valeurs et à décider entre plusieurs actions. Pour cette première leçon, une seule action suffit : afficher un message choisi, exactement comme tu l’as demandé.

## Exemple guidé 1

```python
print("Bonjour")
```
