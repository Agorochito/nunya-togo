## Explication pas à pas

Dans la leçon précédente, tu as distingué l’éditeur et la console. Nous allons maintenant lire une instruction caractère par caractère. Dans print("Bienvenue"), print est le nom de l’action. La parenthèse ouvrante annonce ce que nous donnons à cette action. Le guillemet ouvrant annonce le début d’un texte ; le guillemet fermant annonce sa fin. Enfin, la parenthèse fermante termine l’appel de print.

Un texte est appelé une chaîne de caractères. Un caractère peut être une lettre, un chiffre écrit dans le texte, un espace ou un signe de ponctuation. La chaîne "Lomé 2" contient notamment un espace. Python conserve ces caractères dans leur ordre. Ainsi, "Bonjour Togo" et "BonjourTogo" sont deux chaînes différentes. Les tests d’un exercice peuvent donc te signaler un espace oublié même si le message paraît proche.

Tu peux entourer une chaîne de guillemets doubles droits ou de guillemets simples droits. Le début et la fin doivent utiliser le même type. Pour écrire L’école, l’apostrophe fait partie du message. Des guillemets doubles autour de l’ensemble permettent de conserver cette apostrophe sans la confondre avec une fermeture. Les guillemets décoratifs d’un traitement de texte ne remplacent pas les caractères droits du code.

Chaque appel à print termine normalement sa ligne. Deux appels produisent donc deux lignes successives dans la console. Si tu inverses les instructions dans l’éditeur, tu inverses les lignes du résultat. Cette propriété paraît simple, mais elle sera utile pour expliquer les résultats de programmes plus longs. Commence toujours par prévoir l’ordre avant d’exécuter le programme.

Dans les exercices, la consigne demande un résultat précis. Tu peux changer les mots dans un exemple pour explorer, puis revenir à la consigne avant de vérifier. Ne recopie pas les guillemets autour du résultat attendu dans la console : ils servent à écrire la chaîne dans l’éditeur. En revanche, une ponctuation placée à l’intérieur des guillemets fait réellement partie du message et doit apparaître dans le résultat.

## Exemple guidé 1

```python
print("L’école ouvre")
```

## Exemple guidé 2

```python
print('Kara')
print('Dapaong')
```
