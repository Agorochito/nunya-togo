## Explication pas à pas

Un programme est lu par un ordinateur, mais aussi par des personnes. Toi-même, tu peux revenir demain sur un programme écrit aujourd’hui et avoir oublié pourquoi tu l’as organisé ainsi. Un commentaire est une note destinée à ces lecteurs. En Python, le signe # commence un commentaire lorsqu’il est écrit en dehors d’une chaîne. Python ignore alors la fin de cette ligne pendant l’exécution.

Tu peux placer un commentaire seul sur une ligne, avant une instruction. Tu peux aussi écrire une instruction, puis un espace et un commentaire sur la même ligne. Dans les deux cas, la note ne doit pas apparaître dans la console. Elle explique une intention ; elle ne demande pas d’afficher un message. C’est print qui envoie un message à la console, pas le commentaire.

Le signe # n’a pas le même rôle à l’intérieur d’une chaîne. Dans print("#1"), les guillemets annoncent du texte ; le signe appartient donc au message à afficher. Pour comprendre une ligne, commence par repérer où se trouvent les guillemets. Une note après la fermeture de la chaîne peut être un commentaire, tandis qu’un signe entre les guillemets reste un caractère ordinaire.

Un bon commentaire donne une information utile. Écrire « affiche Bonjour » juste au-dessus de print("Bonjour") répète ce que l’on voit déjà. Écrire « message d’accueil du club » peut expliquer le rôle du message dans un programme. Le commentaire doit rester exact : si tu modifies le code, relis aussi sa note. Un commentaire faux peut rendre le programme plus difficile à comprendre qu’une absence de commentaire.

Pour essayer sans perdre une ligne, tu peux ajouter # devant elle. Cette instruction ne sera plus exécutée. On parle parfois de « commenter une ligne ». Cette technique sert à isoler un problème, mais pense à retirer le signe si tu veux remettre l’instruction en service. Dans les exercices, observe quelles lignes doivent être affichées et lesquelles doivent seulement expliquer ton code. N’ajoute pas des print pour toutes les notes : une explication destinée au lecteur du programme n’est pas forcément une information destinée à son utilisateur.

## Exemple guidé 1

```python
# Message du club
print("Bienvenue au club")
```

## Exemple guidé 2

```python
print("#1") # Numéro de la séance
```
