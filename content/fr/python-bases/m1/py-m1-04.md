## Explication pas à pas

Une erreur n’est pas un jugement sur tes capacités. C’est un message qui décrit un obstacle rencontré par Python. La syntaxe est l’ensemble des règles d’écriture d’un langage. Une SyntaxError signifie que le programme ne respecte pas l’une de ces règles. Par exemple, une chaîne commencée sans être fermée ou une parenthèse oubliée empêche Python de savoir où une instruction se termine.

Face à une erreur, commence par lire le nom du problème et le numéro de ligne indiqué. Le message peut montrer l’endroit où Python s’est arrêté. Cette indication aide à chercher, mais le caractère manquant peut se trouver juste avant. Si une parenthèse est ouverte sur une ligne et n’est jamais fermée, Python peut seulement constater le problème plus tard. Regarde donc aussi la ligne précédente.

Utilise une méthode régulière. Relis la consigne pour savoir ce que tu veux obtenir. Vérifie ensuite les paires de guillemets et les paires de parenthèses. Compare le nom print à l’exemple : les lettres minuscules comptent. Change un seul détail, puis relance le programme. Si tu modifies plusieurs choses à la fois, tu risques de ne plus savoir quelle modification a résolu le problème.

Il faut distinguer une erreur d’écriture d’un résultat incorrect. Le programme print("Kara") est compréhensible pour Python. Si l’exercice demandait Lomé, le programme s’exécute mais ne répond pas à la consigne. Le test signale alors un résultat différent, pas forcément une SyntaxError. La première question est donc : « le programme peut-il être lu ? » ; la seconde : « fait-il ce qui était demandé ? ».

Dans cette leçon, tous les exemples guidés sont des programmes corrects. Les exercices « trouve l’erreur » présentent volontairement un début de programme à réparer. Lis la trace de l’exemple correct avant de tenter une réparation. Tu n’as pas besoin de mémoriser tous les noms d’erreurs aujourd’hui. Apprends surtout à garder le message, repérer la ligne concernée et vérifier une hypothèse simple. Cette habitude te servira lorsque tes programmes auront des conditions, des boucles et plusieurs étapes.

## Exemple guidé 1

```python
print("Je vérifie")
print("Puis je relance")
```
