## Explication pas à pas

Une fonction qui lit toutes ses données avec input est difficile à réutiliser dans un autre contexte. Les paramètres lui permettent de recevoir directement les informations utiles. Dans def saluer(nom):, nom est un paramètre : un nom disponible à l’intérieur du bloc pendant l’appel. Dans saluer("Awa"), le texte Awa est un argument : une valeur fournie pour cet appel précis. Le paramètre n’est donc pas une personne particulière ; il désigne la valeur reçue cette fois-ci.

Une fonction peut recevoir plusieurs paramètres, séparés par des virgules. Avec def afficher_total(prix, nombre):, l’appel afficher_total(200, 3) associe 200 à prix et 3 à nombre. Les exercices utilisent des arguments dans l’ordre de la définition. Inverser deux valeurs peut laisser un programme fonctionner tout en lui donnant un sens différent. Pour un format d’étiquette, la distinction entre nom et activité est immédiatement visible dans le texte produit.

La définition ne demande pas de lire une saisie supplémentaire. Le programme principal peut lire un nom, l’associer à une variable, puis appeler saluer(prenom). Python évalue l’argument et le transmet ; la fonction utilise sa valeur à travers le paramètre. On peut aussi appeler la même fonction avec une valeur littérale. Ces deux formes utilisent le même mécanisme.

Dans ce chapitre, les fonctions affichent encore leur résultat avec print. Cet affichage est une action destinée à la console. Il ne fournit pas automatiquement une valeur calculée à une autre instruction. Le prochain chapitre introduira return pour cette transmission. Pour le moment, précise dans le nom et le contrat qu’il s’agit d’afficher : cela évite de promettre une fonction de calcul réutilisable alors qu’elle ne fait que montrer un message.

Les activités appliquent ces règles dans quatre situations complémentaires. Le paramètre varie à chaque appel, alors que la structure du salut reste la même. L’espace doit être écrit explicitement pour séparer les deux textes. Le contrat fixe l’ordre des informations reçues et affichées. Deux textes peuvent avoir le même type tout en représentant des rôles qu’il ne faut pas intervertir. La conversion utilise une donnée fournie à l’appel. Le cas zéro vérifie l’absence de décalage et plusieurs valeurs montrent que le résultat n’est pas fixé à un exemple. Un paramètre obligatoire ne reçoit pas une valeur par magie. Le programme appelant doit fournir son argument, même lorsqu’une variable contient déjà la donnée disponible.

Avant chaque essai, distingue les informations fournies à l’appel et ce qui doit ressortir de la fonction. Une définition n’est pas une exécution. Suis l’ordre des instructions et le retour au programme appelant. Les valeurs des exercices sont fictives et respectent les limites annoncées. Les tests peuvent appeler la fonction avec plusieurs valeurs : une réponse écrite spécialement pour un exemple ne respecte pas le contrat général.

## Exemple guidé 1

```python
def saluer(nom):
    print("Bonjour " + nom)
saluer("Awa")
saluer("Lina")
```

## Exemple guidé 2

```python
def afficher_total(prix, nombre):
    print(prix * nombre)
afficher_total(200, 3)
```
