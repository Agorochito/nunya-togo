## Explication pas à pas

Lorsqu’un petit programme répète la même tâche à plusieurs endroits, on peut donner un nom à cette tâche. Une fonction rassemble des instructions sous un nom. La ligne def afficher_accueil(): annonce sa définition ; les deux-points ouvrent un bloc indenté. Les parenthèses font partie de l’écriture, même lorsqu’aucune information n’est fournie. Dans cette première étape, les fonctions affichent des messages ou lisent elles-mêmes leurs données.

Définir une fonction ne lance pas son bloc. Python enregistre la définition, puis continue après celle-ci. L’instruction afficher_accueil() appelle la fonction : le programme entre dans son bloc, exécute les instructions dans l’ordre, puis revient à la ligne qui suit l’appel. Si aucun appel n’a lieu, les messages placés dans la fonction ne sont pas affichés. Ce décalage entre définition et exécution explique beaucoup de premiers programmes silencieux.

Un appel peut être répété dans une boucle. La fonction réalise à chaque fois la même séquence, avec les nouvelles valeurs éventuellement lues. Il faut placer la définition avant le premier appel exécuté pour que le nom existe à ce moment. Un nom de fonction décrit une action : afficher_carte est plus utile que truc. Une indentation incorrecte peut placer une instruction hors du bloc et changer le moment où elle s’exécute.

Pour tracer les exemples, ajoute une colonne « endroit courant » à ton tableau : programme principal ou fonction. Numérote les appels, puis les instructions réalisées pour chacun. Ne confonds pas le nombre de lignes de la définition avec le nombre d’exécutions : une même ligne peut être exécutée plusieurs fois, ou jamais. Au prochain chapitre, les paramètres permettront de fournir les informations directement à l’appel au lieu de les lire dans le bloc.

Les activités appliquent ces règles dans quatre situations complémentaires. L’appel déclenche le bloc enregistré par la définition. Cette première activité distingue un programme qui connaît une tâche d’un programme qui la réalise effectivement. La fonction évite de recopier les deux affichages dans la boucle. Lorsque le nombre demandé est nul, aucune exécution du bloc n’a lieu. Chaque appel recommence les instructions et reçoit la saisie suivante. La réutilisation concerne le traitement ; elle ne fige pas la donnée du premier appel. L’emplacement d’une définition et celui d’un appel ont des rôles différents. Placer la définition plus tôt ne place pas son affichage plus tôt dans la sortie.

Avant chaque essai, distingue les informations fournies à l’appel et ce qui doit ressortir de la fonction. Une définition n’est pas une exécution. Suis l’ordre des instructions et le retour au programme appelant. Les valeurs des exercices sont fictives et respectent les limites annoncées. Les tests peuvent appeler la fonction avec plusieurs valeurs : une réponse écrite spécialement pour un exemple ne respecte pas le contrat général.

## Exemple guidé 1

```python
def afficher_accueil():
    print("Bienvenue")
print("Avant")
afficher_accueil()
print("Après")
```

## Exemple guidé 2

```python
def afficher_etape():
    print("Prêt")
for tour in range(2):
    afficher_etape()
```
