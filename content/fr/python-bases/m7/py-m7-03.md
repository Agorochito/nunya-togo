## Explication pas à pas

Une association fictive veut calculer plusieurs cotisations réduites sans recopier la formule. La fonction doit fournir un nombre que le programme pourra conserver, additionner ou afficher plus tard. Le mot return transmet une valeur au programme appelant et termine cet appel. Dans resultat = doubler(4), la valeur retournée par doubler devient celle associée au nom resultat. L’affichage n’est pas nécessaire pour réaliser cette transmission.

Comparons deux fonctions. Une fonction qui exécute print(8) montre huit dans la console, mais ne transmet pas automatiquement huit. Sans return explicite, un appel se termine avec None, une valeur spéciale qui indique ici l’absence de résultat calculé. Une fonction qui exécute return 8 fournit huit, même si la console reste silencieuse. Un print placé après return dans le même chemin ne sera pas atteint. Le choix entre affichage et retour dépend donc du contrat, pas de l’apparence obtenue à l’écran.

Pour le calcul de remise, les arguments sont un montant positif ou nul et un pourcentage compris entre zéro et cent. Les autres entrées sont exclues de cette activité : nous n’exigeons pas silencieusement une gestion d’exceptions. La part retirée vaut montant multiplié par pourcentage puis divisé par cent. Le résultat est le montant moins cette part. Les nombres reçus ne doivent pas être modifiés et aucun affichage n’est demandé.

Un pourcentage nul conserve le montant ; cent pour cent donne zéro. Les tests incluent un montant décimal. Les flottants représentent certains décimaux de manière approchée : la vérification accepte une petite différence absolue annoncée de 0,000000001. Cela ne définit pas une règle de comptabilité réelle. Le traitement de monnaie réelle et des arrondis demanderait une représentation et un contrat distincts.

Les activités appliquent ces règles dans quatre situations complémentaires. La fonction transmet le nouveau montant sans imprimer. Les tests du taux nul, de la remise totale et d’un décimal vérifient les limites et le contrat numérique. Le transfert remplace le contexte de cotisation par une durée, mais conserve le même principe : fournir un résultat réutilisable à partir d’un argument. Une valeur retournée peut être ajoutée à d’autres totaux sans devoir relire une sortie de console. Le cas décimal contrôle aussi la nature numérique du résultat. Le programme initial semble montrer la bonne réponse, mais renvoie None. Le test d’appel distingue ce défaut d’une fonction qui transmet réellement le résultat.

Avant chaque essai, distingue les informations fournies à l’appel et ce qui doit ressortir de la fonction. Une définition n’est pas une exécution. Suis l’ordre des instructions et le retour au programme appelant. Les valeurs des exercices sont fictives et respectent les limites annoncées. Les tests peuvent appeler la fonction avec plusieurs valeurs : une réponse écrite spécialement pour un exemple ne respecte pas le contrat général.

## Exemple guidé 1

```python
def doubler(nombre):
    return nombre * 2
resultat = doubler(4)
print(resultat + 1)
```

## Exemple guidé 2

```python
def montrer(nombre):
    print(nombre)
def fournir(nombre):
    return nombre
a = montrer(4)
b = fournir(4)
print(a)
print(b)
```
