## Explication pas à pas

Une décision peut dépendre de plusieurs informations. Jusqu’ici, tu testais surtout une seule comparaison à la fois. Les opérateurs logiques and, or et not permettent de combiner ou d’inverser des réponses booléennes. Ils ne remplacent pas les comparaisons : ils relient leurs résultats pour construire une condition qui exprime plus précisément la règle souhaitée.

Avec and, les deux conditions doivent être vraies. Pour un achat fictif, stock > 0 and budget >= prix demande à la fois un stock disponible et un budget suffisant. Si une seule de ces conditions échoue, l’ensemble est faux. Avec or, une seule condition vraie suffit. C’est utile pour reconnaître l’un ou l’autre de deux jours, par exemple jour == "samedi" or jour == "dimanche".

Chaque côté d’un opérateur doit exprimer une condition complète. La formule jour == "samedi" or "dimanche" ne pose pas la seconde question correctement : elle utilise directement une chaîne à la place d’une comparaison. Répète donc le nom de variable quand tu compares la même valeur à plusieurs possibilités. Les parenthèses peuvent aider à regrouper des conditions et à montrer l’intention du programme.

not inverse un booléen : not True vaut False et not False vaut True. Si accord est déjà une valeur booléenne, if not accord signifie que le bloc concerne l’absence d’accord. Ne confonds pas cette opération avec une chaîne de texte contenant le mot "False". Tu peux obtenir un booléen en comparant une saisie, comme accord = input() == "oui".

Il est aussi possible de placer un if dans le bloc d’un autre if. On parle de choix imbriqués. Chaque niveau d’indentation correspond à un niveau de décision. Ce procédé aide à vérifier d’abord un accès général, puis un détail seulement si l’accès est possible. Aligne chaque else avec le if qu’il complète et dessine les chemins possibles avant de tester ton code : cette petite carte réduit les confusions entre les différents refus.

## Exemple guidé 1

```python
stock = 2
budget = 600
prix = 500
if stock > 0 and budget >= prix:
    print("Possible")
else:
    print("Attendre")
```

## Exemple guidé 2

```python
acces = True
badge = False
if acces:
    if badge:
        print("Entrer")
    else:
        print("Présenter le badge")
else:
    print("Accès fermé")
```
