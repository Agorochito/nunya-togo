## Explication pas à pas

Tu vas réunir les outils de ce module dans un petit programme complet. Le programme lira des résultats, vérifiera leurs limites, calculera une moyenne et choisira un message. Il s’agit d’un bilan d’entraînement inventé pour apprendre Python. Les seuils et les mentions de cette leçon ne sont pas des critères du BEPC, du BAC ou d’un établissement togolais. Ils n’indiquent aucune décision d’admission ou de réussite officielle.

Commence par distinguer les entrées, les calculs et les sorties. Les entrées sont ici des notes entières. Le calcul d’une moyenne simple consiste à additionner toutes les notes puis à diviser par leur nombre. Avec trois notes, le dénominateur est trois, même si leurs valeurs changent. La division / produit un résultat qui peut s’écrire avec une partie décimale, par exemple 14.0.

Avant le calcul, vérifie que les données respectent l’intervalle annoncé pour l’exercice, de zéro à vingt inclus. Pour une seule note, tu peux écrire note >= 0 and note <= 20. Pour plusieurs notes, les vérifications doivent toutes être vraies. Une note valide ne suffit pas à rendre les autres valides. Si une donnée est hors limites, affiche le message demandé au lieu de calculer un bilan trompeur.

Après le calcul, une chaîne if/elif/else choisit le repère de progression. Notre règle fictive utilise « Très bien » à partir de seize, « Bien » à partir de quatorze, « En progrès » à partir de dix et « À renforcer » en dessous. Les tests commencent par le seuil le plus élevé pour éviter que les meilleures moyennes soient capturées par une catégorie plus large.

Termine en affichant les informations avec les f-strings déjà étudiées. Une sortie précise facilite les vérifications : ne modifie pas les libellés attendus pendant que tu corriges le calcul. Teste une moyenne égale à chaque seuil, une valeur inférieure et une entrée invalide. Pour analyser un bug, contrôle successivement les saisies, la validation, le nombre de notes utilisé comme dénominateur et l’ordre des conditions.

## Exemple guidé 1

```python
n1 = 12
n2 = 14
n3 = 16
moyenne = (n1 + n2 + n3) / 3
print(f"Moyenne : {moyenne}")
```

## Exemple guidé 2

```python
moyenne = 14
if moyenne >= 16:
    print("Très bien")
elif moyenne >= 14:
    print("Bien")
elif moyenne >= 10:
    print("En progrès")
else:
    print("À renforcer")
```
