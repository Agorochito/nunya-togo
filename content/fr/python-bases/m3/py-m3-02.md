## Explication pas à pas

Une comparaison calcule une réponse, mais elle ne modifie pas à elle seule le chemin suivi par le programme. L’instruction if permet maintenant d’exécuter un bloc seulement lorsque sa condition est vraie. On écrit if, une condition, puis deux-points. Les instructions du bloc se placent sur les lignes suivantes, avec un décalage régulier appelé indentation. Nous utiliserons quatre espaces pour rendre cette structure visible.

Quand la condition est fausse, Python ignore le bloc if. Si tu souhaites faire autre chose dans ce cas, ajoute else suivi de deux-points. else n’a pas besoin d’une nouvelle condition : il représente le cas qui reste. Son alignement est celui du if auquel il appartient, et les instructions de son propre bloc sont à nouveau décalées de quatre espaces.

Avec un if et un else, un seul de ces deux blocs est exécuté pendant le passage dans cette structure. Par exemple, si stock vaut zéro, une condition stock > 0 est fausse : le message du premier bloc n’est pas affiché, puis le message du else l’est. Si stock vaut cinq, c’est le premier bloc qui s’exécute et le second qui est ignoré.

Observe aussi les instructions placées après la structure, sans indentation. Elles ne sont plus dans le if ni dans le else et s’exécutent après le choix. C’est pratique pour afficher un message commun, mais cela peut créer un bug si tu croyais que cette ligne dépendait encore de la condition. L’espacement fait partie de la syntaxe de Python : ce n’est pas seulement une préférence esthétique.

Pour vérifier une condition, choisis des données qui passent par chaque bloc. Tester uniquement un stock positif pourrait cacher un else manquant ou un mauvais message. Si la règle contient un seuil, conserve les essais aux frontières appris dans la leçon précédente. Avant d’exécuter le code, suis le trajet au crayon : évalue la condition, sélectionne un bloc et note exactement quelles lignes seront affichées.

## Exemple guidé 1

```python
stock = 0
if stock > 0:
    print("Disponible")
else:
    print("À réapprovisionner")
```

## Exemple guidé 2

```python
montant = 600
if montant >= 500:
    print("Budget suffisant")
else:
    print("Budget insuffisant")
print("Vérification terminée")
```
