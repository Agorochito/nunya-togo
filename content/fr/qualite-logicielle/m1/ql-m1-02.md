## Explication pas à pas

Une fonction peut recevoir une infinité de valeurs : on ne peut pas toutes les tester. Il faut donc choisir les cas les plus révélateurs. Deux idées guident ce choix.

La première est la classe d’équivalence. On regroupe les entrées qui doivent produire le même genre de résultat. Pour un tarif de car selon l’âge, gratuit avant 5 ans, réduit avant 18 ans et plein ensuite, il y a trois classes valides : 0 à 4, 5 à 17, 18 et plus. Il y a aussi une classe invalide : les âges négatifs, qui doivent être refusés. Tester 30 et 40 apporte peu : ces deux valeurs sont dans la même classe. Un représentant par classe suffit pour vérifier le comportement général.

La seconde idée concerne les frontières. La plupart des erreurs viennent d’un < écrit à la place d’un <=, ou d’un décalage d’une unité. Ces erreurs ne changent rien au milieu d’une classe ; elles ne se voient qu’à la frontière. Pour une limite à 18 ans, on teste 17 et 18 ; pour une limite à 5 ans, 4 et 5. Un test qui ne vérifie que des valeurs éloignées des frontières laisse passer ces erreurs.

Pour une liste, les cas limites classiques sont la liste vide, une liste d’un seul élément, une liste où tous les éléments sont égaux, et des valeurs en première ou en dernière position. Pour un texte : le texte vide, des espaces, des majuscules, des accents. Pour un nombre : zéro, un nombre négatif, un très grand nombre.

Les entrées invalides méritent aussi des tests. Si une fonction doit refuser un âge négatif avec une ValueError, le test doit vérifier que l’erreur est bien levée. On l’écrit avec try et except : on appelle la fonction dans le try, et si on arrive à la ligne suivante sans erreur, le test échoue avec assert False ; dans except ValueError, tout va bien. pytest fournit un raccourci, pytest.raises, qui fait la même chose.

Cette méthode a un nom dans le métier : on parle d’analyse aux valeurs limites. Elle est simple, mais elle trouve une grande partie des erreurs réelles. Avant d’écrire un test, dessine les classes sur une ligne, marque les frontières, puis choisis tes valeurs : une au milieu de chaque classe, et une de chaque côté de chaque frontière.

## Exemple guidé 1

```python
def tarif(age):
    if age < 0:
        raise ValueError("âge invalide")
    if age < 5:
        return 0
    if age < 18:
        return 500
    return 1000

for age in [4, 5, 17, 18, 40]:
    print(age, tarif(age))
```

Affichage attendu :

    4 0
    5 500
    17 500
    18 1000
    40 1000

Trace :

- 4 et 5 encadrent la première frontière.
- 17 et 18 encadrent la seconde.
- 40 représente la classe adulte.

## Exemple guidé 2

```python
def tarif(age):
    if age < 0:
        raise ValueError("âge invalide")
    if age < 5:
        return 0
    if age < 18:
        return 500
    return 1000

try:
    tarif(-1)
    print("Erreur : l’âge négatif est accepté")
except ValueError:
    print("Âge négatif bien refusé")
```

Affichage attendu :

    Âge négatif bien refusé

Trace :

- L’appel lève une ValueError.
- La ligne qui suit l’appel n’est pas exécutée.
- Le except confirme le refus.
