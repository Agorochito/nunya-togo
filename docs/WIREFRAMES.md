# Écrans et structure

1. Accueil : Continuer → deux cartes Mes cours / Mon avenir → Révision du jour → progrès par objectif.
2. Profil : choix d’objectif → statut → cycle/classe/série → expérience → âge facultatif pour confidentialité → point de départ.
3. Point de départ : une question → réponses + Je découvre → progression → recommandation sans classement.
4. Catalogue : recherche → domaines → cours → modules → leçons ; ressources tierces et contenus originaux distingués.
5. Leçon : plan → Lire / Pas à pas / Pratiquer / Vidéo facultative → retour bienveillant → carnet → prochaine étape.
6. Aide : contexte de la leçon → indices locaux → IA si configurée et en ligne ; état honnête sinon.
7. Hors ligne : contenus enregistrés → taille → export/import → espace disponible ; aucune vidéo imposée.
8. Métier : mission → journée type → compétences → chemin d’apprentissage → matières utiles → études et sources à confirmer.

Dossiers : dist/ (application), content/fr et content/en (rédaction), data/ (référentiels), docs/ (décisions et relecture), scripts/ (imports et validation), lib/ai (contrat fournisseur), prompts/ (génération), supabase/migrations (modèle et politiques à déployer).
