# Application du prompt Qwen — version 5.8.0

Le document fourni le 5 novembre sert de cahier des charges produit. L’application existante reste une PWA statique ; aucune réécriture Next.js, Tailwind ou Prisma n’est nécessaire pour ces fonctions. La progression reste locale selon le choix du propriétaire.

| Demande | Mise en œuvre |
|---|---|
| Palette chaude, navigation latérale, accueil et recherche | Déjà présents ; conservés. |
| Niveau 0 et Python débutant détaillé | 20 leçons de découverte et 53 leçons Python déjà présentes ; conservées. |
| Catalogue lisible, filtres et raccourcis | 9 programmes rédigés, dont deux niveaux Python distincts ; Git et niveau 0 accessibles séparément. |
| Progression intermédiaire | Nouvelle série Python de 6 modules / 18 leçons, avec 72 exercices, 36 exemples, 54 questions et projet. DOM reste la suite intermédiaire JavaScript. |
| Parcours entre cours | Front-end, analyse de données, fondations back-end et prérequis cybersécurité ; dialogue avec ordre des cours, annulation et confirmation. Aucun cours absent ajouté artificiellement. |
| Préserver la progression lors d’un changement | Objectif séparé des brouillons, réponses, positions et validations. Reprise du premier cours inachevé ; objectif inclus dans les sauvegardes. |
| Fiches PDF ou HTML | Export HTML autonome d’une leçon ou d’un cours ; impression PDF depuis le navigateur. Texte, exemples, exercices, quiz et corrigés, sans moteur ni progression intégrés au fichier. |
| Certificat de fin | Bilan local de progression téléchargeable, explicitement sans diplôme ou certification professionnelle. |
| Français et interface anglaise | Nouvelles actions de parcours dans un dictionnaire FR/EN ; contenu pédagogique et titres français. La traduction intégrale existante de l’interface reste à poursuivre. |
| Backend avec Linux/Docker, spécialisation cybersécurité | Les parcours expliquent leurs limites ; ces programmes supplémentaires ne sont pas encore rédigés et exécutables. |

Le nombre de ressources externes ne représente pas un nombre de programmes Nunya complets. Les contenus originaux sont en brouillon et demandent une relecture pédagogique humaine. La cible plus large de 72 cours reste suivie dans COURSE_COVERAGE_AUDIT.md et la matrice JSON ; ce lot ne la déclare pas terminée.
